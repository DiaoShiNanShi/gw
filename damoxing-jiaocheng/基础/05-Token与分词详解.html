基础 05：Token 与分词详解（AI 怎么「读」文字）

基础模块

学习目标：彻底搞懂 Token、BPE、词表、为什么中文比英文「费 Token」。

1. Token 是什么？

AI 不直接处理「字」或「单词」，而是处理 Token（文字碎片）。分词器把句子切成模型认识的碎片列表。

"我爱北京天安门" → ["我", "爱", "北京", "天安门"]  或 ["我爱", "北京", "天安门"]

不同模型切法不同，所以同一段话 Token 数可能差 20%。

2. 三种主流分词算法

算法原理谁在用
BPE从字符开始，高频组合合并GPT、Llama
WordPiece类似 BPE，用似然选合并BERT
SentencePiece把空格也当字符，中英统一Qwen、Llama 多语言

3. 中英文 Token 差异

语言大约计费影响
英文1 token ≈ 0.75 个单词相对省
中文1 token ≈ 1~2 个汉字同样内容中文更费
代码符号多，token 碎片化Prompt 里代码很贵

4. 上下文窗口与 Token 预算

128K 窗口 ≠ 能塞 12 万字。要留出生成空间。工程经验：输入 70% + 输出 30% 分配。

5. 实战：怎么数 Token？

# tiktoken（OpenAI）
import tiktoken
enc = tiktoken.encoding_for_model('gpt-4')
print(len(enc.encode('你好世界')))  # 约 4
