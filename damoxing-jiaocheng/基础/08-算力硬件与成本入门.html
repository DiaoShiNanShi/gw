2. 显存估算（FP16）

7B 模型 ≈ 14GB（参数）+ KV Cache + 激活
13B ≈ 26GB
70B ≈ 140GB（需多卡）

Q4 量化：显存约 ÷ 4
7B Q4 ≈ 4~6GB 可推理

3. API 成本怎么算

按 Token 计费：输入 + 输出分开算。DeepSeek 约 ¥1/百万输入 Token（2026 参考价，以官网为准）。

# 估算：1000 次对话，每次 500 input + 300 output token
input_cost = 1000 * 500 / 1e6 * 1  # 元
output_cost = 1000 * 300 / 1e6 * 2
print(f'月成本约 {input_cost+output_cost:.1f} 元')
