04-常用插件与实战案例

大白话版 · 常用插件与实战案例（小白向）
目标：学会常用插件选型（照片/相机、本地存储、支付、推送、分享）、权限处理，并通过一个完整小项目（待办清单）从 0 到 1 的拆解打通全流程。

一、先讲"是什么"：插件到底是什么？

一句话版本：插件 = 别人写好的"现成零件"，装上就能用，帮你省掉造轮子的时间。

打个比方：

你要开一家餐厅（做 App），不需要自己种菜、养猪、打铁锅——
去"批发市场"（pub.dev）买现成的：
- 拍照功能 → 买个"相机模块"
- 保存数据 → 买个"冷库模块"
- 收钱 → 接个"支付收银台"

插件就是这些现成零件，flutter pub add 插件名 一行命令装进来。

去哪里找插件： pub.dev（Flutter 官方插件市场，相当于 iOS 的 CocoaPods 仓库）。

选插件的"防坑三看"（必学）：

看什么 为什么 怎么看
看评分/点赞 用的人多 = 靠谱 pub.dev 的 like 数
看更新日期 长期不更新 = 可能已死 看 last updated
看维护者 官方/大厂维护 = 稳 看 publisher（如 flutter.dev 官方）

二、再讲"为什么"：为什么要用插件？

理由 大白话
省时间 拍照/支付/推送自己写要几个月，插件现成
稳定 热门插件被千万人用过，坑都填完了
跨平台 一个插件同时支持 iOS/Android，不用写两遍
专注业务 把时间花在自己的核心功能上

但要注意（反面）：
- 别乱装：一个功能装一个插件，插件越多包越大、冲突越多。
- 别装没人维护的：出了 bug 没人修，只能自己啃源码。
- 大插件慎重：能用系统能力（如 WebView）就用系统的。

3.2 本地存储

需求 推荐插件 大白话
存小数据（设置/登录态） shared_preferences 存键值对（像 UserDefaults）
存结构化数据 sqflite / drift 本地数据库（像 SQLite）
存文件（图片/下载） path_provider 获取 App 目录路径 
// shared_preferences 用法（存/读小数据）
import 'package:shared_preferences/shared_preferences.dart';

// 存
Future<void> saveLogin(bool isLogin) async {
  final prefs = await SharedPreferences.getInstance();
  await prefs.setBool('is_login', isLogin);
}

// 读
Future<bool> readLogin() async {
  final prefs = await SharedPreferences.getInstance();
  return prefs.getBool('is_login') ?? false;
}

对 iOS 工程师：shared_preferences ≈ UserDefaults，sqflite ≈ SQLite/CoreData（更接近 SQLite）。

3.3 支付

大白话先说清： 支付是"高危区"，每个平台规则不同，务必按官方文档来。

平台 推荐方式 关键注意
iOS 内购（App 内购买） in_app_purchase（官方） 必须走苹果支付，否则审核被拒
Android 内购 in_app_purchase（官方） 走 Google Play Billing
微信/支付宝（国内） 官方 SDK 插件（如 fluwx） 需要商户资质、签名匹配

支付核心规则（必记）：
1. 虚拟商品（会员、金币） → 必须用苹果/谷歌内购（App Store 审核红线）。
2. 实物商品（买衣服、外卖） → 可以用微信/支付宝。
3. 支付结果必须后端二次验证（别只信客户端回调，客户端可被伪造）。

3.4 推送

需求 推荐方案 大白话
iOS 推送 firebase_messaging（最主流） 接 APNs 的现成方案
Android 推送 firebase_messaging / 国内厂商通道 国内用厂商 SDK 或极光/个推
本地通知（定时提醒） flutter_local_notifications 不联网，本地弹通知

推送大白话流程：

服务器 → 推送服务(FCM/APNs) → 手机系统 → 你的 App → 弹通知

注意坑：
- iOS 推送需要开发者账号配置 APNs 证书/密钥。
- 国内 Android 没有统一推送（谷歌被墙），要用厂商通道（小米/华为/OPPO/vivo）或聚合服务。

3.5 分享

需求 推荐插件 大白话
分享文字/链接/图片 share_plus 调系统分享面板
微信/QQ 分享 fluwx 等 接微信 SDK 
// share_plus 用法（调起系统分享面板）
import 'package:share_plus/share_plus.dart';

对 iOS 工程师：share_plus ≈ UIActivityViewController，一行调起系统分享。

3.6 权限处理（必学！）

大白话： 用相机/相册/定位前，必须先向系统申请权限，否则会崩溃或被拒。

iOS 需要在 Info.plist 声明用途（少一个就闪退！）：

<!-- ios/Runner/Info.plist 里添加 -->
<key>NSCameraUsageDescription</key>
<string>需要使用相机拍照</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>需要访问相册选择图片</string>
<key>NSLocationWhenInUseUsageDescription</key>
<string>需要使用定位显示附近内容</string>

Flutter 端用 permission_handler 统一申请：

// 用 permission_handler 申请相机权限
import 'package:permission_handler/permission_handler.dart';

Future<void> requestCamera() async {
  final status = await Permission.camera.request();  // 申请
  if (status.isGranted) {
    print('权限已授予');
  } else {
    print('权限被拒绝');
    // 引导用户去设置页打开：openAppSettings();
  }
}

权限处理三原则：
1. 先声明再申请：iOS 必须先在 Info.plist 写用途说明。
2. 合理时机申请：用的时候再申请，别一启动就弹一堆权限框（审核也不喜欢）。
3. 被拒要引导：拒绝后引导用户去系统设置打开（openAppSettings()）。

第 2 步：定义数据模型（Model）

// lib/features/todo/domain/todo_item.dart
class TodoItem {
  final String id;
  final String title;
  final bool isDone;

  const TodoItem({
    required this.id,
    required this.title,
    this.isDone = false,
  });

  // 转成 Map（用于存到 shared_preferences）
  Map<String, dynamic> toJson() => {
        'id': id,
        'title': title,
        'isDone': isDone,
      };

  // 从 Map 解析（用于读回来）
  factory TodoItem.fromJson(Map<String, dynamic> json) => TodoItem(
        id: json['id'] as String,
        title: json['title'] as String,
        isDone: json['isDone'] as bool,
      );

  // 复制一份改 isDone（不可变风格）
  TodoItem copyWith({bool? isDone}) =>
      TodoItem(id: id, title: title, isDone: isDone ?? this.isDone);
}

第 3 步：状态管理（Provider + ChangeNotifier）

// lib/features/todo/presentation/todo_model.dart
import 'package:flutter/foundation.dart';
import 'package:shared_preferences/shared_preferences.dart';
import '../domain/todo_item.dart';

class TodoModel extends ChangeNotifier {
  final List<TodoItem> _items = [];

  List<TodoItem> get items => List.unmodifiable(_items);  // 只读暴露

  // 添加待办
  void add(String title) {
    _items.add(TodoItem(
      id: DateTime.now().millisecondsSinceEpoch.toString(),
      title: title,
    ));
    _save();
    notifyListeners();
  }

  // 切换完成状态
  void toggle(String id) {
    final index = _items.indexWhere((e) => e.id == id);
    if (index != -1) {
      _items[index] = _items[index].copyWith(isDone: !_items[index].isDone);
      _save();
      notifyListeners();
    }
  }

  // 删除
  void remove(String id) {
    _items.removeWhere((e) => e.id == id);
    _save();
    notifyListeners();
  }

  // 保存到本地（shared_preferences）
  Future<void> _save() async {
    final prefs = await SharedPreferences.getInstance();
    final jsonList = _items.map((e) => e.toJson()).toList();
    await prefs.setString('todos', jsonList.toString());  // 存成字符串
  }

  // 启动时读取本地数据
  Future<void> load() async {
    final prefs = await SharedPreferences.getInstance();
    final raw = prefs.getString('todos');
    if (raw == null) return;
    // 简单解析：这里用 jsonEncode/decode 更严谨，示例从简
  }
}

第 4 步：界面（UI）

// lib/features/todo/presentation/todo_page.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';
import 'todo_model.dart';

class TodoPage extends StatelessWidget {
  const TodoPage({super.key});

  @override
  Widget build(BuildContext context) {
    final model = context.watch<TodoModel>();  // 监听状态变化

    return Scaffold(
      appBar: AppBar(title: const Text('我的待办')),
      body: model.items.isEmpty
          ? const Center(child: Text('暂无待办，点右下角添加'))
          : ListView.builder(
              itemCount: model.items.length,
              itemBuilder: (context, index) {
                final item = model.items[index];
                return ListTile(
                  leading: Checkbox(
                    value: item.isDone,
                    onChanged: (_) => model.toggle(item.id),
                  ),
                  title: Text(
                    item.title,
                    style: item.isDone
                        ? const TextStyle(
                            decoration: TextDecoration.lineThrough,  // 完成划线
                            color: Colors.grey,
                          )
                        : null,
                  ),
                  trailing: IconButton(
                    icon: const Icon(Icons.delete),
                    onPressed: () => model.remove(item.id),
                  ),
                );
              },
            ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => _showAddDialog(context),
        child: const Icon(Icons.add),
      ),
    );
  }

  // 弹出输入框添加待办
  Future<void> _showAddDialog(BuildContext context) async {
    final controller = TextEditingController();
    final title = await showDialog<String>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('添加待办'),
        content: TextField(controller: controller),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context),
            child: const Text('取消'),
          ),
          TextButton(
            onPressed: () => Navigator.pop(context, controller.text),
            child: const Text('添加'),
          ),
        ],
      ),
    );
    if (title != null && title.trim().isNotEmpty) {
      context.read<TodoModel>().add(title.trim());  // 调用添加
    }
  }
}

第 5 步：组装入口（main.dart）

// lib/main.dart
import 'package:flutter/material.dart';
import 'package:provider/provider.dart';
import 'features/todo/presentation/todo_model.dart';
import 'features/todo/presentation/todo_page.dart';

void main() {
  runApp(
    ChangeNotifierProvider(          // 提供全局 TodoModel
      create: (_) => TodoModel()..load(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: '待办清单',
      theme: ThemeData(colorSchemeSeed: Colors.blue),
      home: const TodoPage(),
    );
  }
}

七、本节动手练习（含答案提示）

练习 1：插件选型

以下需求分别选哪个插件？A. 选照片　B. 存登录状态　C. 分享文字

✅ 答案提示：A image_picker；B shared_preferences（小数据键值对）；C share_plus。

练习 2：权限配置

在 iOS 上使用相机拍照，除了申请运行时权限，还必须做什么才不会闪退？

✅ 答案提示：在 ios/Runner/Info.plist 里添加 NSCameraUsageDescription（用途说明），否则 iOS 直接闪退。

练习 3：支付红线

一个 App 卖"会员订阅"，用户想用微信支付，行不行？为什么？

✅ 答案提示：不行。虚拟商品（会员/金币）在 iOS 必须走苹果内购（in_app_purchase），用第三方支付会被 App Store 审核拒绝。

练习 4：实战拆解

待办清单 App 的数据保存，为什么选 shared_preferences 而不是 sqflite？

✅ 答案提示：数据量小、结构简单（纯字符串列表），shared_preferences 够用且简单；数据量大、查询复杂（多表、搜索）才需要 sqflite。

练习 5：状态管理回顾

待办清单里 context.watch<TodoModel>() 和 context.read<TodoModel>() 有什么区别？

✅ 答案提示：watch 在 build 里用（监听变化自动重建）；read 在事件回调里用（只读一次，不监听，避免多余重建）。
