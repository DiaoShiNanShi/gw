02-Dart 语言基础

大白话版 · Dart 语法速成（小白向）
目标：学完本篇，你能看懂并写出最基本的 Dart 代码，为学 Widget 打好地基。

一、先讲"是什么"：Dart 是一门什么样的语言？

一句话版本：Dart 是谷歌开发的编程语言，也是 Flutter 的"官方母语"——写 Flutter App 用的就是 Dart。

打个比方：

Flutter 是一座装修精美的房子（App 界面），Dart 就是盖房子用的"钢筋水泥"（代码）。
你想让 Flutter 干活，就得用 Dart 跟它说话，就像你想让 Siri 干活，得说它能听懂的话一样。

Dart 的特点（大白话版）：

  • 好学：语法长得像 C / Java / JavaScript / Swift 的混合体，你只要会任何一门主流语言，上手极快。
  • 强类型 + 类型推断：既能明确写类型，也能让电脑自己猜。
  • 面向对象：万物皆对象，所有东西都是"类"的实例。
  • 自带异步：Future + async/await，写网络请求、读文件这些"等一等"的操作非常顺手。
  • 能编译成两种东西：开发时用 JIT（快，支持热重载），发布时用 AOT（编译成机器码，跑得快）。

二、变量与类型（Dart 的"抽屉和盒子"）

2.1 怎么声明一个变量

在 Dart 里，变量就像一个"贴了标签的盒子"，你要往里面放东西，先说清楚盒子里放什么（或者让 Dart 自己猜）。

void main() {
  // 1. 明确指定类型（最严谨，推荐新手用）
  int age = 18;              // 整数：年龄
  double price = 9.9;        // 小数：价格
  String name = '小明';       // 字符串：名字（单引号双引号都行）
  bool isStudent = true;     // 布尔：是/否

  // 2. 用 var 让 Dart 自己猜类型（省事）
  var city = '北京';          // Dart 自动推断出 city 是 String
  var count = 100;           // Dart 自动推断出 count 是 int

  // 3. 用 final / const 表示"以后不能改"（安全，推荐）
  final String birthday = '2000-01-01';  // final：运行时才确定，但确定后不可改
  const double pi = 3.14159;             // const：编译时就确定，永远不可改

  // 打印输出（相当于 Swift 的 print）
  print('我叫$name，今年$age岁，住在$city');
  // 上面用了字符串插值：$变量名 或 ${表达式}
}

大白话解释几个概念：

关键字 意思 类比
int / double / String / bool 基础类型 不同尺寸的盒子
var 让 Dart 猜类型 "你先看着放，反正装对就行"
final 只能赋值一次 贴了封条的盒子，打开后不能换内容
const 编译期常量 出厂就印死的铭牌，永不改变

2.2 常用内置类型速览

void main() {
  // 数字
  int a = 10;
  double b = 3.14;
  // 字符串
  String s1 = '你好';
  String s2 = "世界";
  String s3 = '可以拼接 $s1 $s2';   // 插值
  // 布尔
  bool ok = true;
  // 列表 List（相当于 Swift 的数组 Array）
  List<String> fruits = ['苹果', '香蕉', '橘子'];
  print(fruits[0]);              // 苹果（下标从 0 开始）
  fruits.add('西瓜');             // 追加一个元素
  // 映射 Map（相当于 Swift 的字典 Dictionary）
  Map<String, int> scores = {'语文': 90, '数学': 95};
  print(scores['语文']);          // 90
  // 集合 Set（去重）
  Set<int> nums = {1, 2, 2, 3};  // 里面只有 1,2,3（2 自动去重）
}

对 iOS 工程师：List ≈ Array，Map ≈ Dictionary，Set ≈ Set，几乎一一对应。

三、函数（Dart 的"小机器"）

函数就像一个"小机器"：你塞进去原料（参数），它吐出成品（返回值）。

// 1. 最普通的函数：有返回值
int add(int x, int y) {
  return x + y;
}

// 2. 没有返回值：用 void
void sayHello(String name) {
  print('你好，$name！');
}

// 3. 箭头函数：只有一行代码时的简写（=> 后面就是返回值）
int multiply(int x, int y) => x * y;

// 4. 可选命名参数：调用时可以传也可以不传（用 { } 包起来）
void makeCoffee({String type = '美式', int sugar = 0}) {
  print('做了一杯$type，加$sugar块糖');
}

// 5. 可选位置参数：用 [ ] 包起来
void greet(String name, [String? title]) {
  // 这里的 ? 表示 title 可以为空（null）
  if (title != null) {
    print('$title $name');
  } else {
    print('你好，$name');
  }
}

void main() {
  print(add(1, 2));          // 3
  sayHello('小红');           // 你好，小红！
  print(multiply(3, 4));     // 12
  makeCoffee();               // 做了一杯美式，加0块糖
  makeCoffee(type: '拿铁', sugar: 2);  // 做了一杯拿铁，加2块糖
  greet('小王');              // 你好，小王
  greet('老王', '张');         // 张 老王
}

对 iOS 工程师： void 相当于 Swift 的 Void；可选命名参数有点像 Swift 的默认参数；=> 就是 Swift 里单表达式函数的简化写法。

四、类（Dart 的"图纸"）

类是"生产对象的图纸"。你先画一张图纸（class），然后用它造出一个个具体对象（实例）。

// 定义一个"狗"类
class Dog {
  // 属性（成员变量）
  String name;
  int age;

  // 构造函数：造狗的时候必须提供名字和年龄
  // 这里的 this.name = name 简写成了 this.name（Dart 特有简写）
  Dog(this.name, this.age);

  // 方法：狗会叫
  void bark() {
    print('$name 汪汪叫！今年 $age 岁了');
  }

  // 方法：返回一个描述字符串
  String describe() => '一只叫$name的狗，$age岁';
}

void main() {
  // 用图纸造出两只狗
  Dog dog1 = Dog('旺财', 2);
  Dog dog2 = Dog('来福', 3);

  dog1.bark();      // 旺财 汪汪叫！今年 2 岁了
  print(dog2.describe());  // 一只叫来福的狗，3岁
}

4.1 继承（儿子继承老爸的家产）

// 父类：动物
class Animal {
  String name;
  Animal(this.name);

  void speak() {
    print('$name 发出声音');
  }
}

// 子类：猫，继承动物
class Cat extends Animal {
  // 调用父类构造函数
  Cat(String name) : super(name);

  // 重写父类方法（覆盖 speak）
  @override
  void speak() {
    print('$name 喵喵叫');
  }
}

void main() {
  Cat cat = Cat('咪咪');
  cat.speak();  // 咪咪 喵喵叫
}

对 iOS 工程师：class、extends、@override 和 Swift 的 class / 继承 / override 概念一模一样。

五、异步（Dart 的"点外卖"）

异步就是：先下单（发出请求），不傻等，该干嘛干嘛，外卖到了再处理。

  • Future ≈ 一个"将来会送到的外卖单子"
  • async ≈ 标记"这个函数会点外卖（有异步操作）"
  • await ≈ "站在这等外卖送到再继续往下走"
// 模拟一个网络请求：2 秒后返回数据
Future<String> fetchData() async {
  // Future.delayed 就是"等 2 秒"
  await Future.delayed(Duration(seconds: 2));
  return '服务器返回的数据';
}

// async 函数：里面可以用 await 等待
Future<void> loadPage() async {
  print('开始加载...');
  String data = await fetchData();  // 在这里等 2 秒
  print('拿到数据：$data');
  print('加载完成！');
}

void main() {
  loadPage();
  print('主流程继续执行，不会卡住');  // 这行会先打印出来！
}

大白话理解运行顺序：

开始加载...            ← loadPage 开始执行
主流程继续执行，不会卡住   ← main 不等待，立刻继续
（等待 2 秒...）
拿到数据：服务器返回的数据   ← await 等到了结果，继续往下
加载完成！

对 iOS 工程师：Future ≈ Swift 的 async 函数返回值（Task），async/await 和 Swift 5.5+ 的 async/await 几乎一模一样，你完全可以照搬思维。

六、iOS 开发者视角（Swift vs Dart 对照表）

Swift 概念 Dart 对应 说明
let / var final / var 常量 / 变量
Int / Double / String / Bool int / double / String / bool 基础类型（首字母大小写注意）
Array<Int> List<int> 数组
Dictionary<String, Int> Map<String, int> 字典
func 函数直接写 函数定义
class / override class / @override 类和重写
async / await async / await 异步
guard let / 可选值 ? / !（空安全） 处理可能为空的值
print print 打印输出（同名）
String(describing:) toString() / $插值 转字符串

给你的三条忠告：
1. Dart 用 $变量名 做字符串插值，比 Swift 的 \() 更省事，别写错成 Swift 语法。
2. Dart 的类型写在变量名后面（int x），不是 Swift 的 x: Int。
3. Dart 的 List / Map 是内置类型，不像 Swift 要写 Array / Dictionary 那么正式，随意用。

七、小节小结

  1. Dart 是 Flutter 的官方语言，语法像 C/Java/JS/Swift 的混合体，很好上手。
  2. 变量用 int / double / String / bool / var / final / const 声明。
  3. 常用容器：List（数组）、Map（字典）、Set（去重集合）。
  4. 函数支持默认参数、命名参数、箭头函数简写。
  5. 类支持属性、构造函数、继承、方法重写。
  6. 异步用 Future + async/await，和 Swift 的写法几乎一样。

八、本节动手练习（含答案提示）

练习 1：修 Bug

下面的代码有一处错误，请找出来并修复：
dart void main() { var name = '小明'; name = 18; // 这里报错了 print(name); }

✅ 答案提示：var name 已经被推断为 String 类型，不能再赋值为数字 18。要么改成 var name = 18;，要么换一个变量存年龄。

练习 2：写一个函数

写一个函数 double square(double x)，返回 x 的平方，并在 main 里调用打印结果。

✅ 答案提示：
dart double square(double x) => x * x; void main() => print(square(5)); // 25

练习 3：创建类

定义一个 Person 类，有 name 和 age 两个属性，一个 introduce() 方法打印"我叫xxx，今年xx岁"，然后创建一个实例并调用。

✅ 答案提示：
dart class Person { String name; int age; Person(this.name, this.age); void introduce() => print('我叫$name，今年$age岁'); } void main() { Person p = Person('小红', 20); p.introduce(); }

练习 4：异步小实验

写一个 Future<String> getWeather()，等 1 秒后返回"晴天"，再用 async/await 打印结果。

✅ 答案提示：
dart Future<String> getWeather() async { await Future.delayed(Duration(seconds: 1)); return '晴天'; } Future<void> main() async { print(await getWeather()); }

练习 5：概念连线

把 Swift 概念和 Dart 概念连线：let ↔ ？　Array ↔ ？　Dictionary ↔ ？　async/await ↔ ？

✅ 答案提示：let ↔ final；Array ↔ List；Dictionary ↔ Map；async/await ↔ async/await。
