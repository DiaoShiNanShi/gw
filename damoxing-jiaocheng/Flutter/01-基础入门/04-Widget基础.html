04-Widget 基础

大白话版 · 万物皆 Widget（小白向）
目标：理解 Flutter 最核心的思想，学会用 StatelessWidget / StatefulWidget 和常用基础组件搭界面。

一、先讲"是什么"：万物皆 Widget 到底是什么意思？

一句话版本：在 Flutter 里，屏幕上你看到的一切——文字、图片、按钮、甚至整个页面——都是一个 Widget（小部件）。

打个比方：

搭 Flutter 界面就像拼乐高积木：
- 每一块积木都是一个 Widget（文字块、图片块、按钮块……）
- 积木可以套娃：一块大积木里可以放很多小积木
- 整个 App 就是一棵"积木树"（Widget 树），根是 runApp，往下不断分叉

iOS 原生里"视图层级"（UIView 套 UIView）你肯定很熟——Widget 树就是 Flutter 版的视图层级。

Widget 的三个特点（大白话）

  1. 一切皆 Widget：文字、图片、按钮、输入框、列表、页面、甚至"间距""居中"这种看不见的东西，都是 Widget。
  2. Widget 嵌套 Widget：Widget 像俄罗斯套娃，一个套一个，形成一棵树。
  3. Widget 是不可变的"图纸"：Widget 本身只是一份"描述"，每次界面变化，Flutter 都会重新"按图纸施工"（重建 Widget 树），但底层只会更新真正变化的部分（这就是 Flutter 高效的秘密）。

看一个最简单的 Widget 树

import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    // 这棵树从上到下：MaterialApp → Scaffold → Center → Text
    return MaterialApp(          // 根：App 外壳
      home: Scaffold(            // 页面骨架
        body: Center(            // 居中容器
          child: Text('我是最小的一棵 Widget 树'),  // 叶子：文字
        ),
      ),
    );
  }
}

这棵树长这样（从上往下看）：

MaterialApp          ← 整个 App 的壳
  └─ Scaffold        ← 一页的骨架（标题栏+身体）
       └─ Center     ← 把内容放中间
            └─ Text  ← 显示文字

二、再讲"为什么"：为什么用 Widget 这种设计？

  • 简单统一：只有一个概念（Widget），学一个就能举一反三，不用记一大堆控件类名。
  • 组合优于继承：想要"红色的大按钮"，不是去创建一个新类，而是把 ElevatedButton 包在 Padding/SizedBox/ColoredBox 里组合出来。积木嘛，拼就完事了。
  • 界面 = 代码：整个 UI 用代码声明，没有 Storyboard / XIB 那种"拖拽 + 代码"双轨制，逻辑清晰、易审查、易复用。
  • 性能好：Widget 是不可变描述，Flutter 只对变化部分做最小更新，所以界面再复杂也流畅。

三、怎么用：StatelessWidget vs StatefulWidget

Flutter 的组件分两大类，先记住一句话：

StatelessWidget（无状态）：界面内容固定不变，像一张"打印好的名片"。
StatefulWidget（有状态）：界面内容会变，像一块"电子屏幕"，能根据状态刷新。

3.1 StatelessWidget（无状态组件）

内容不会变化的页面用这个。比如"关于页面"、"静态展示页"。

import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Scaffold(
        body: Center(
          child: AboutCard(),   // 使用我们自定义的静态卡片
        ),
      ),
    );
  }
}

// 自定义一个无状态组件：一张不会变的"名片"
class AboutCard extends StatelessWidget {
  const AboutCard({super.key});

  @override
  Widget build(BuildContext context) {
    // build 方法就是"按图纸施工"：返回这棵子树长什么样
    return Card(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          mainAxisSize: MainAxisSize.min,  // 让 Column 只占内容大小
          children: [
            const Text('我是无状态组件', style: TextStyle(fontSize: 20)),
            const SizedBox(height: 8),     // 垂直间距（这也是 Widget！）
            const Text('我的内容永远不变'),
          ],
        ),
      ),
    );
  }
}

3.2 StatefulWidget（有状态组件）

内容会随用户操作/数据变化的页面用这个，比如"计数器"、"点赞按钮"。

关键理解（大白话）：
- StatefulWidget 本身也是"图纸"（不变的壳）
- 真正的"活数据"放在 State 里（会变的灵魂）
- 数据一变，调用 setState() 通知 Flutter："我要刷新！"

import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: CounterPage(),
    );
  }
}

// 第一步：定义 StatefulWidget（一个壳）
class CounterPage extends StatefulWidget {
  const CounterPage({super.key});

  // 必须实现 createState，返回对应的 State
  @override
  State<CounterPage> createState() => _CounterPageState();
}

// 第二步：定义 State（真正的状态和界面）
// 下划线 _ 开头表示私有（只在当前文件可用）
class _CounterPageState extends State<CounterPage> {
  int _count = 0;  // 状态：当前计数

  // 按钮点击时调用的方法
  void _increment() {
    setState(() {
      // 在 setState 里修改状态，界面会自动重建刷新
      _count++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('计数器')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('你点了 $_count 次', style: const TextStyle(fontSize: 28)),
            const SizedBox(height: 16),
            // 按钮：点击后调用 _increment
            ElevatedButton(
              onPressed: _increment,   // 点击回调
              child: const Text('点我 +1'),
            ),
          ],
        ),
      ),
    );
  }
}

运行逻辑（大白话）：

点击按钮 → 调用 _increment() → setState 把 _count 加 1
→ Flutter 收到"状态变了" → 重新执行 build() 重建界面
→ 界面上数字变成新值

对 iOS 工程师：setState() ≈ 手动触发 view.setNeedsLayout() + 重新渲染。区别是 Flutter 帮你自动 diff，只更新变化的部分。

五、iOS 开发者视角（老司机对照表）

iOS 原生 Flutter 大白话
UIView Widget 一切界面的最小单元
UIViewController 一个 Widget（通常配 Scaffold） 一屏内容的管理者
UILabel Text 显示文字
UIImageView Image / Icon 显示图片/图标
UIButton ElevatedButton / TextButton / OutlinedButton 按钮
UITextField TextField 输入框
UIStackView Row / Column 线性布局
Auto Layout 布局 Widget（Center/Padding/Align 等） 摆位置
UITableView ListView 滚动列表
UINavigationBar AppBar 顶部导航
setNeedsLayout + 重绘 setState() 通知界面刷新
Storyboard / XIB 纯代码声明 UI Flutter 没有可视化拖拽

给 iOS 工程师的三句话总结：
1. 你把"视图层级"的思维直接搬过来，只是名字从 UIView 换成 Widget。
2. 把"约束/Frame"的思维换成"布局 Widget"（Center、Padding、Row、Column），上手很快。
3. 状态刷新从"手动 reload"变成 setState()，反而更省心。

六、小节小结

  1. 万物皆 Widget：Flutter 界面是一棵"Widget 树"，一切皆积木、积木套积木。
  2. StatelessWidget：内容不变的静态组件（名片）。
  3. StatefulWidget：内容会变的组件，用 setState() 触发刷新（电子屏）。
  4. 常用组件：Text / Image / Icon / 按钮三兄弟 / Container / Row / Column / Stack / ListView。
  5. 布局核心思想：用布局 Widget 摆位置，组合出任意界面。

七、本节动手练习（含答案提示）

练习 1：判断类型

一个显示"当前时间"的页面，时间每秒变化，应该用 StatelessWidget 还是 StatefulWidget？为什么？

✅ 答案提示：StatefulWidget。因为时间会变化，需要 State 保存数据并用 setState 刷新。

练习 2：搭一个小界面

用 Column 搭一个竖排界面：上面一个 Icon（点赞图标），中间一段文字，下面一个按钮，整体居中。

✅ 答案提示：用 Column(mainAxisAlignment: MainAxisAlignment.center, children: [Icon(...), SizedBox(height: 8), Text(...), SizedBox(height: 8), ElevatedButton(...)])，外面套 Center 或让 Column 占满。

练习 3：理解 setState

下面的代码点击按钮后界面会变吗？为什么？
dart void _increment() { _count++; // 没有 setState }

✅ 答案提示：不会变。_count 虽然改了，但没有调用 setState() 通知 Flutter 重建界面。必须把修改放进 setState(() { _count++; }); 里。

练习 4：连线题

连线：Text ↔ ？　Image ↔ ？　Row ↔ ？　ListView ↔ ？　setState ↔ ？

✅ 答案提示：Text ↔ UILabel；Image ↔ UIImageView；Row ↔ UIStackView(横向)；ListView ↔ UITableView；setState ↔ 通知界面刷新（setNeedsLayout + 重绘）。

练习 5：改造计数器

把计数器改成"点赞数"：图标用 Icons.thumb_up，按钮文字改为"点赞"，点赞数从 100 开始。

✅ 答案提示：_count 初始值改成 100；Icon(Icons.thumb_up)；按钮 child: Text('点赞')；显示文字改为 '点赞 $_count'。其余逻辑不变。
