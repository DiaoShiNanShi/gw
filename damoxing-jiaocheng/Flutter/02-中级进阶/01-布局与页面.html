01-布局与页面

大白话版 · 常用布局组件与页面搭建（小白向）
目标：学会用 Container / Row / Column / Stack / Expanded / Flex / ListView / GridView 搭出各种页面，并理解"布局套路"。

一、先讲"是什么"：布局到底在布什么？

一句话版本：布局 = 决定"每个零件放在屏幕的哪个位置、占多大地方"。

打个比方：

你要布置一个客厅（屏幕）：
- Row = 沙发、茶几、电视柜在一排摆开（水平排列）
- Column = 书架从上到下一列摆（垂直排列）
- Stack = 装饰画叠在墙纸上面（层叠）
- Container = 一个能调大小、颜色、圆角的"收纳盒"（万能容器）
- Expanded = 告诉某个家具"剩下的空间都给你"（弹性分配）

布局组件就是这些"摆放规则"，让你不用像原生那样一个个算坐标，而是用"声明式"的语言说清楚怎么摆。

布局思维的关键转变（对 iOS 工程师特别重要）

  • iOS 原生：用 Auto Layout 约束（leading/trailing/top/bottom/width/height）描述相对关系。
  • Flutter：用"布局组件嵌套"描述结构。你不再想"这个控件离左边 16pt"，而是想"这个控件外面包一层 Padding，左边 16"。

二、再讲"为什么"：为什么 Flutter 要用组件嵌套来布局？

  1. 代码即结构：看代码就能脑补出页面长啥样，不用切 Storyboard。
  2. 组合自由：Row 套 Column、Column 套 Row、任意嵌套，能摆出任何复杂页面。
  3. 无需计算坐标：不用手动算 frame，组件自己会根据"父容器的约束"决定大小。
  4. 跨平台一致：布局逻辑一套，iOS/Android 渲染结果一样。

三、怎么用：逐个击破常用布局组件

3.1 Container（万能收纳盒）

Container 是 Flutter 里最常用的"万能盒子"，可以设置：大小、背景色、圆角、边框、内边距、外边距、对齐方式。

Container(
  width: 200,                    // 宽
  height: 100,                   // 高
  margin: const EdgeInsets.all(16),     // 外边距（盒子外留白）
  padding: const EdgeInsets.all(8),     // 内边距（盒子内留白）
  decoration: BoxDecoration(            // 装饰：颜色、圆角、边框、阴影
    color: Colors.blue,                 // 背景色
    borderRadius: BorderRadius.circular(12),  // 圆角
    boxShadow: const [                  // 阴影
      BoxShadow(color: Colors.grey, blurRadius: 8),
    ],
  ),
  alignment: Alignment.center,   // 内部内容居中
  child: const Text('我是收纳盒里的内容'),
)

对 iOS 工程师：Container ≈ 一个可设置背景色、圆角、阴影的 UIView，padding ≈ layoutMargins，margin ≈ 约束间距。

3.2 Row 与 Column（一横一竖两兄弟）

  • Row：子组件水平排列（像横向 UIStackView）
  • Column：子组件垂直排列（像纵向 UIStackView）
// 水平排列：头像 + 名字 + 年龄
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,  // 主轴（水平）方向分配方式
  crossAxisAlignment: CrossAxisAlignment.center,      // 交叉轴（垂直）方向对齐
  children: [
    Icon(Icons.account_circle, size: 40),
    const Text('小明'),
    const Text('18岁'),
  ],
),

// 垂直排列：标题 + 内容 + 按钮
Column(
  mainAxisAlignment: MainAxisAlignment.center,  // 主轴（垂直）居中
  crossAxisAlignment: CrossAxisAlignment.start, // 交叉轴（水平）靠左
  children: [
    const Text('标题', style: TextStyle(fontSize: 20)),
    const SizedBox(height: 8),   // 间距
    const Text('内容描述...'),
    const SizedBox(height: 16),
    ElevatedButton(onPressed: () {}, child: const Text('按钮')),
  ],
),

MainAxisAlignment 常用值（大白话）：

值 效果 类比
start 从开头排 都靠左（Column）
center 居中排 都居中
end 从结尾排 都靠右
spaceBetween 两端贴边，中间均匀分布 字与字拉开
spaceEvenly 每个间距相等 均匀铺开

3.3 Expanded 与 Flex（弹性空间分配）

Expanded 是布局的灵魂：它让子组件瓜分父容器剩余的空间。

// 三块横条：中间那块占 2 份，两边各 1 份
Row(
  children: [
    Expanded(
      flex: 1,   // 占 1 份
      child: Container(color: Colors.red, height: 100),
    ),
    Expanded(
      flex: 2,   // 占 2 份（是别人的两倍宽）
      child: Container(color: Colors.green, height: 100),
    ),
    Expanded(
      flex: 1,
      child: Container(color: Colors.blue, height: 100),
    ),
  ],
)
// 结果：红:绿:蓝 = 1:2:1 的宽度比例

对 iOS 工程师：Expanded(flex: n) ≈ 自动布局里的等宽约束 / 分布比例（类似 UIStackView 的 distribution: .fillEqually 但可以自定义权重）。

Flex 是什么？ Row 和 Column 都是 Flex 的子类。Flex 是"通用弹性布局"，Flex(direction: Axis.horizontal) 就等于 Row，Flex(direction: Axis.vertical) 就等于 Column。一般直接用 Row/Column 就行，Flex 了解即可。

3.4 Stack（层叠布局）

Stack 让子组件叠在一起，后面的盖在前面的上面。配合 Positioned 可以精确定位。

// 在背景图上叠一个"返回按钮"和"底部标题"
Stack(
  children: [
    // 第一层：背景图
    Container(
      width: 300, height: 200,
      color: Colors.grey,
    ),
    // 第二层：左上角返回按钮（Positioned 精确定位）
    const Positioned(
      left: 10, top: 10,
      child: Icon(Icons.arrow_back, color: Colors.white),
    ),
    // 第三层：底部居中标题
    const Positioned(
      left: 0, right: 0, bottom: 10,
      child: Text('叠在底部的标题', textAlign: TextAlign.center),
    ),
  ],
)

对 iOS 工程师：Stack ≈ 在同一个父 view 上叠放多个子 view（用 frame 定位），Positioned ≈ 设置 frame 的偏移。

3.5 ListView（滚动列表，≈ UITableView）

列表是 App 里最常见的组件。ListView 有两种玩法：

// 玩法一：少量固定条目（简单直接）
ListView(
  children: [
    ListTile(leading: Icon(Icons.star), title: Text('条目 1')),
    ListTile(leading: Icon(Icons.star), title: Text('条目 2')),
    ListTile(leading: Icon(Icons.star), title: Text('条目 3')),
  ],
),

// 玩法二：大量数据（用 builder 按需生成，性能好，≈ cellForRowAt）
ListView.builder(
  itemCount: 100,                    // 一共 100 条
  itemBuilder: (context, index) {    // 每条怎么画
    return ListTile(
      leading: const Icon(Icons.list),
      title: Text('第 $index 条数据'),
    );
  },
),

对 iOS 工程师：ListView.builder 的 itemBuilder ≈ cellForRowAt 代理方法，都是"按需创建 cell"，性能思路完全一样。

3.6 GridView（网格布局，≈ UICollectionView）

// 三列网格：图片墙、商品列表都可以用它
GridView.count(
  crossAxisCount: 3,                  // 每行 3 列
  mainAxisSpacing: 8,                 // 行间距
  crossAxisSpacing: 8,                // 列间距
  children: List.generate(9, (index) {
    return Container(
      color: Colors.primaries[index % Colors.primaries.length],
      child: Center(child: Text('$index')),
    );
  }),
),

对 iOS 工程师：GridView.count(crossAxisCount: 3) ≈ 三列的 UICollectionView 流水布局。

四、布局套路（面试常考 + 实战必用）

套路 1：居中显示 → Center 包一层

Center(child: Text('居中文字'))

套路 2：卡片列表 → Column 套 Card

Column(
  children: [
    Card(child: ListTile(title: Text('第一张卡片'))),
    Card(child: ListTile(title: Text('第二张卡片'))),
  ],
)

套路 3：头部 + 内容 + 底部按钮 → Column + Expanded

Column(
  children: [
    const Text('顶部标题'),          // 固定
    Expanded(child: ListView(...)),  // 中间内容占满剩余空间并可滚动
    ElevatedButton(onPressed: () {}, child: const Text('底部按钮')),  // 固定
  ],
)

套路 4：头像 + 信息 + 按钮 → Row + Expanded

Row(
  children: [
    const CircleAvatar(child: Icon(Icons.person)),  // 头像
    const SizedBox(width: 12),
    const Expanded(child: Text('姓名和描述信息，超出会自动换行...')),
    ElevatedButton(onPressed: () {}, child: const Text('关注')),
  ],
)

响应式（适配不同屏幕）

大白话：同一个页面，在 iPhone 14 和 iPad 上都能好看地显示，就叫响应式。

简单做法：
1. 多用 Expanded / Flexible 弹性布局，别写死宽度。
2. 用 MediaQuery 获取屏幕尺寸，大屏换布局。

// 获取屏幕宽度（相当于 UIScreen.main.bounds.width）
double screenWidth = MediaQuery.of(context).size.width;

// 大屏（>600 宽，比如 iPad）显示两列，小屏显示一列
GridView.count(
  crossAxisCount: screenWidth > 600 ? 2 : 1,
  children: [...],
)

五、iOS 开发者视角（老司机对照表）

给 iOS 工程师的真心话：
你最大的"坑"是习惯用约束精确控制位置，而 Flutter 更强调"结构决定布局"。多写几个页面后你会发现，Flutter 的布局代码比 Auto Layout 直观得多——因为你看代码就知道结构，而不是去解一坨约束方程组。

六、小节小结

  1. 布局 = 用组件嵌套描述"零件放哪、占多大"。
  2. Container 是万能盒子（颜色/圆角/边距/阴影）。
  3. Row 横排、Column 竖排、Stack 层叠，是三大布局基石。
  4. Expanded 弹性分配空间，解决"剩余空间给谁"的问题。
  5. ListView 做列表、GridView 做网格，都是按需生成的性能王者。
  6. 响应式核心：弹性布局 + MediaQuery 判断屏幕宽度。

七、本节动手练习（含答案提示）

练习 1：三选一

想实现"三个按钮等宽横排"，应该用哪个组件组合？写出核心代码。

✅ 答案提示：Row + 三个 Expanded 各包一个按钮：
dart Row(children: [ Expanded(child: ElevatedButton(...)), SizedBox(width: 8), Expanded(child: ElevatedButton(...)), SizedBox(width: 8), Expanded(child: ElevatedButton(...)), ])

练习 2：实现头像+文字+按钮

实现一个"左侧圆形头像、中间姓名文字（可换行）、右侧关注按钮"的行布局。

✅ 答案提示：Row + CircleAvatar + Expanded(Text) + ElevatedButton（见"套路 4"）。

练习 3：理解 Expanded

一个 Row 里有两个 Expanded，flex 分别为 1 和 3，总宽 400，两个容器各多宽？

✅ 答案提示：总份数 1+3=4，每份 400/4=100。第一个 1×100=100，第二个 3×100=300。

练习 4：列表优化

有 10000 条数据要展示，应该用 ListView(children: [...]) 还是 ListView.builder？为什么？

✅ 答案提示：用 ListView.builder。它是按需生成（懒加载），只有滚动到可见区域才创建条目，性能好；直接传 10000 个 children 会一次性全部创建，卡顿甚至崩溃。

练习 5：响应式判断

在 iPad 上（宽 1024）希望一行显示 4 个商品，在 iPhone 上（宽 390）一行显示 2 个，怎么写？

✅ 答案提示：
dart double w = MediaQuery.of(context).size.width; GridView.count(crossAxisCount: w > 600 ? 4 : 2, ...);
