学习方法建议（给小白）

  1. 先读后练：基础 → 中级 → 高级 全部读完，再进练习模块动手。
  2. 不懂就跳过：高级模块个别名词如果卡住，先跳过，做完练习再回头看，往往会豁然开朗。
  3. 动手最重要：大模型是"玩"会的，不是"看"会的。环境搭建好以后，多跑、多试、多问。
  4. 每章都有例子：教程里所有"示例"都值得亲手敲一遍（尤其是练习模块）。
  5. 左侧菜单：随时切换章节；带 ▶ 可运行 的代码块可直接在网页里点运行看效果。

三、你的电脑配置（本教程练习均基于此配置）

项目 配置
芯片 Apple M2（8 核 CPU + 10 核 GPU）
内存 16GB 统一内存
系统 macOS 26.5.2

这个配置能干什么（大白话）：
- ✅ 流畅运行 7B 参数以内的量化模型（相当于手机版的 14 倍智商）
- ✅ 跑 RAG 知识库、微调小模型（LoRA）
- ⚠️ 13B 参数以上的模型会很吃力（内存不够），不建议
- ⚠️ 磁盘只剩 17GB，模型装多了会爆，建议先清理或外接硬盘
