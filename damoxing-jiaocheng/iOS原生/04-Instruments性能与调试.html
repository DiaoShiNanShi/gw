iOS 原生 04：Instruments 性能与调试

iOS 原生模块

学习目标：App 卡、内存爆、AI 推理慢——会用 Instruments 和 Xcode 调试器定位问题。

1. Xcode 调试三板斧

工具查什么
断点 Debugger变量值、调用栈
Console (po / lldb)运行时打印对象
View HierarchyUI 层级、约束冲突
Network InspectorAPI 请求耗时、响应体

2. Instruments 重点模板

模板何时用AI App 场景
Time ProfilerCPU 热点主线程被 Token 解析卡住
Allocations / Leaks内存泄漏聊天列表 cell 没释放
Energy Log耗电端侧模型持续推理发热
Network流量流式 SSE 连接数过多

3. 端侧 AI 性能注意

  • 模型加载放后台线程，完事儿再回 @MainActor 更新 UI
  • 监听 didReceiveMemoryWarning，必要时卸载模型
  • 用 Instruments 看 ANE/GPU 是否真正被 Core ML 用到

4. 常见崩溃类型

  • EXC_BAD_ACCESS → 野指针、强制解包 nil
  • Main Thread Checker → 子线程改了 UI
  • Watchdog → 启动或主线程阻塞超 20 秒
