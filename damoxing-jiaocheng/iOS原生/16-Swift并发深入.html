iOS 原生模块

Swift 5.5+ 现代并发，AI 流式输出必用。

1. async/await

func loadAI() async throws -> String {
    try await aiClient.chat(messages: msgs)
}

2. Actor

Actor 保证内部状态线程安全。共享的 ChatHistory 可声明为 actor。

3. Task 与取消

let task = Task { await longRunningAI() }
task.cancel()  // 用户点停止时取消

4. AsyncStream 流式

LLM 流式输出用 AsyncThrowingStream 往 UI 推 chunk。
