iOS 原生 03：网络、存储与系统框架

iOS 原生模块

学习目标：App 的「水电煤」——网络请求、本地存储、权限、推送。AI App 的 Key 安全也在这章。

1. URLSession 网络（AI API 就靠它）

// GET 请求
let (data, response) = try await URLSession.shared.data(from: url)

// POST JSON（LLM API）
var request = URLRequest(url: apiURL)
request.httpMethod = "POST"
request.setValue("application/json", forHTTPHeaderField: "Content-Type")
request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
request.httpBody = try JSONEncoder().encode(body)

生产架构：App → 你的后端 → 大模型 API。Key 永远在后端。

2. 本地存储选型

方案适合AI 场景
UserDefaults小配置用户偏好、上次选的模型
Keychain敏感信息短期 token（不是 API Key！）
Core Data / SwiftData结构化数据聊天记录持久化
FileManager大文件下载的 GGUF 模型、缓存

3. 常用系统框架（和 AI 相关）

框架干什么
Speech语音识别（语音输入 AI）
AVFoundationTTS 播报、音频播放
Vision本地 OCR、人脸检测
Core ML端侧模型推理
NaturalLanguage分词、语言识别

4. 权限与隐私（上架必查）

  • Info.plist 声明：麦克风、相册、网络用途说明
  • App Tracking Transparency（跟踪用户要弹窗）
  • AI 生成内容需在隐私政策中说明数据如何使用
