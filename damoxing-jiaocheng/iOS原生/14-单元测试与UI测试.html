iOS 原生 14：单元测试与 UI 测试

iOS 原生模块

XCTest、Mock 网络层、UI 自动化。

1. 单元测试

func testChatViewModel() async throws {
    let mock = MockLLMService(reply: "你好")
    let vm = ChatViewModel(service: mock)
    await vm.send("hi")
    XCTAssertEqual(vm.messages.last?.content, "你好")
}

2. UI 测试

XCUITest 自动化点按钮、输入文字。CI 里跑回归。

3. AI 测试难点

LLM 输出不确定 → 断言结构而非具体内容；或用固定 temperature=0 + mock。
