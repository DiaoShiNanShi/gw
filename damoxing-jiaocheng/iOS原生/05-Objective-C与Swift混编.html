iOS 原生 05：Objective-C 与 Swift 混编

iOS 原生模块

老项目大量 OC 代码，新功能用 Swift 写——混编是必修课。

1. 为什么还有 OC

2014 年前的老 App、大量第三方 SDK 仍是 OC。你会维护 legacy 代码。

2. 互调规则

方向做法
Swift 调 OCBridging-Header 导入 .h
OC 调 SwiftXcode 自动生成 ProjectName-Swift.h
.categoryOC 扩展仍常用

3. 示例

// MyClass.h
@interface MyClass : NSObject
- (void)sayHello;
@end

// Swift 里直接 MyClass().sayHello()

4. AI 模块建议

新 AI 功能用 Swift Module 写，OC 项目通过 @objc 暴露接口给老代码调用。
