iOS 原生 06：多线程 GCD 与 Operation

iOS 原生模块

AI 推理不能卡主线程。GCD 是 iOS 并发的基石。

1. 主线程铁律

UI 只能在主线程改。 网络、文件、AI 推理放后台。

2. GCD 队列

DispatchQueue.global(qos: .userInitiated).async {
    let result = heavyWork()
    DispatchQueue.main.async { self.label.text = result }
}

3. QoS 优先级

QoS场景
userInteractiveUI 动画
userInitiated用户触发的 AI 请求
utility下载模型
background清理缓存

4. OperationQueue

需要依赖关系、取消、进度时用 NSOperation。大量 AI 任务可放 OperationQueue 限并发。

5. AI 推理线程

模型 inference 放 DispatchQueue.global(qos: .userInitiated)，结果回 MainActor 更新 UI。
