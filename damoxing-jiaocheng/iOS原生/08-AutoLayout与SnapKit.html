iOS 原生 08：Auto Layout 与 SnapKit

iOS 原生模块

适配所有屏幕尺寸的约束布局。

1. Auto Layout 原理

约束描述视图关系，系统自动算 frame。冲突会报 Ambiguous/Unsatisfiable。

2. SnapKit 写法

view.snp.makeConstraints { make in
    make.top.equalTo(safeAreaLayoutGuide)
    make.leading.trailing.equalToSuperview().inset(16)
    make.height.equalTo(44)
}

3. 常见坑

  • 忘记 translatesAutoresizingMaskIntoConstraints = false
  • 循环约束
  • ScrollView 里 contentLayoutGuide
