iOS 原生模块

学习目标：SwiftUI 声明式 UI + MVVM 架构——新项目和 AI 聊天页的主流写法。

1. SwiftUI vs UIKit

UIKitSwiftUI
写法命令式：create → addSubview → 设约束声明式：描述「长什么样」
状态手动 reloadData@State / @Observable 自动刷新
适用老项目、复杂自定义控件新项目、原型、AI 聊天 UI
 
import SwiftUI

struct ChatView: View {
    @StateObject private var vm = ChatViewModel()

    var body: some View {
        VStack {
            ScrollView {
                ForEach(vm.messages) { msg in
                    Text(msg.content)
                        .padding(8)
                        .background(msg.isUser ? Color.blue.opacity(0.2) : Color.gray.opacity(0.2))
                        .cornerRadius(8)
                }
            }
            HStack {
                TextField("输入...", text: $vm.input)
                Button("发送") { Task { await vm.send() } }
            }.padding()
        }
    }
}

2. MVVM 架构（大白话）

View 只负责显示；ViewModel 管业务逻辑和网络；Model 是数据结构。

@MainActor
class ChatViewModel: ObservableObject {
    @Published var messages: [ChatMessage] = []
    @Published var input = ""

    func send() async {
        let userMsg = ChatMessage(role: "user", content: input)
        messages.append(userMsg)
        input = ""
        // 调 AIClient…
        let reply = try? await AIClient.shared.chat(messages: messages)
        if let r = reply { messages.append(.init(role: "assistant", content: r)) }
    }
}
