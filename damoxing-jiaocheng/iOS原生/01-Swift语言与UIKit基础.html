2. UIKit 核心（MVC 怎么转起来）

大白话：UIKit = 苹果传统的界面积木。Controller 当「包工头」，View 是砖块，Model 是数据。

类干什么
UIViewController管一个屏幕的生命周期（viewDidLoad…）
UIView / UILabel / UIButton界面元素
UITableView / UICollectionView列表（聊天消息列表就是它）
UINavigationController页面栈，push/pop
Auto Layout约束布局，适配不同屏幕
 
// 最小 UITableView 数据源
class ChatListVC: UIViewController, UITableViewDataSource {
    let table = UITableView()
    var messages: [String] = []

    override func viewDidLoad() {
        super.viewDidLoad()
        table.dataSource = self
        table.frame = view.bounds
        view.addSubview(table)
    }

    func tableView(_ tableView: UITableView, numberOfRowsInSection section: Int) -> Int {
        messages.count
    }

    func tableView(_ tableView: UITableView, cellForRowAt indexPath: IndexPath) -> UITableViewCell {
        let cell = tableView.dequeueReusableCell(withIdentifier: "c") ??
            UITableViewCell(style: .default, reuseIdentifier: "c")
        cell.textLabel?.text = messages[indexPath.row]
        return cell
    }
}

3. 生命周期（面试常问）

viewDidLoad      → 视图加载完，只调一次，适合初始化
viewWillAppear   → 每次即将显示（刷新数据）
viewDidAppear    → 已经显示（开动画、埋点）
viewWillDisappear→ 即将离开
viewDidDisappear → 已经离开（停定时器）

4. 和 AI App 的结合点

  • 聊天界面：UITableView / UICollectionView + 流式刷新 cell
  • 网络层：URLSession + async/await 调 LLM API
  • 老项目多是 UIKit，AI 功能常做成独立 Module 再嵌入
