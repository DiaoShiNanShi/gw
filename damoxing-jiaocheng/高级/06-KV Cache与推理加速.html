高级 06：KV Cache 与推理加速全家桶

高级模块

推理慢？显存爆？这章汇总所有加速手段。

1. KV Cache

生成每个新 token 时，前面 token 的 K/V 已经算过，存起来复用。加速明显，但占显存：约 2 × 层数 × 头数 × 维度 × 序列长度。

2. Flash Attention

分块计算 Attention，减少 GPU 显存读写（IO 瓶颈）。训练推理都加速。

3. 其他加速手段

技术作用
Continuous Batching动态组批，提高吞吐
投机解码小模型猜+大模型验
PagedAttentionvLLM 的 KV 分页管理
Tensor Parallel多卡切模型
量化减显存提速度

4. Prefill vs Decode

Prefill：吃完全部输入，并行，算力密集。
Decode：一个字一个字吐，内存带宽密集。
优化重点不同。
