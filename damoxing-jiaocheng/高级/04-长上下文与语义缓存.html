高级 04：长上下文工程与语义缓存

高级模块

学习目标：对话太长怎么办、相同问题怎么省钱——两个工程高频题。

1. 长上下文工程

手段大白话
滑动窗口只保留最近 N 轮
摘要压缩老对话让 AI 总结成一段话
RAG 外置记忆重要事实存向量库，用时再查
128K 长窗口模型贵，且「迷失在中间」问题仍存在

2. 语义缓存（Semantic Cache）

用户问「年假几天」和「公司年假有多少天」意思一样，不必每次都调 LLM。

# 简化语义缓存逻辑
cache = []  # [(question_embedding, answer), ...]

def get_cached(question: str, embed_fn, threshold=0.92):
    q_emb = embed_fn(question)
    for emb, ans in cache:
        if cosine(q_emb, emb) > threshold:
            return ans  # 命中，省钱！
    return None

生产可用 GPTCache、Redis + 向量索引。

小结

长对话靠截断+摘要+RAG；重复问题靠语义缓存，能省 30%~50% API 费用。
