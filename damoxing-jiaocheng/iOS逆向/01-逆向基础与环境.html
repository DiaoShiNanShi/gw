iOS 逆向 01：逆向基础与环境搭建

iOS 逆向模块

⚠️ 法律声明：本教程仅用于安全研究、学习和自己 App 的调试。未经授权逆向他人 App 可能违法，请遵守当地法规和用户协议。

学习目标：搞懂 iOS 逆向在干什么、需要什么环境、核心名词什么意思。

1. 逆向是干什么的？（大白话）

目的例子
安全审计查自己 App 的 API Key 是否能被扒出来
竞品分析看对方用了什么网络协议（注意法律边界）
调试加固越狱环境下 Hook 自己的 App 看加密逻辑
恶意分析安全公司分析木马 App

2. 越狱 vs 非越狱

非越狱（Stock iOS）越狱（Jailbreak）
权限沙盒严格，不能改系统root 权限，可装 Cydia 插件
逆向能力静态分析 IPA、有限动态调试Frida Hook、Cycript、全内存读写
适用砸壳后的静态分析、企业证书包深度 Hook、实时改逻辑

现状：新版本 iOS 越狱越来越难，很多分析转向「砸壳 + 静态分析 + 模拟器调试」。

3. 核心名词

名词大白话
IPAiOS 安装包，本质是 zip
Mach-OiOS 可执行文件格式（类似 Linux 的 ELF）
砸壳去掉 App Store 加密的壳，得到可分析的 binary
class-dump从 Mach-O 导出 Objective-C 头文件（类、方法名）
Hopper / IDA反汇编器，看汇编和伪代码
Frida动态插桩框架，运行时 Hook 任意函数
LLDB苹果官方调试器，Xcode 内置

4. 环境搭建（Mac）

# 常用工具（按需安装）
# class-dump: 导出 OC 头文件
# Hopper Disassembler / IDA Pro: 反汇编
# frida-tools: pip install frida-tools
# objection: pip install objection  # Frida 封装，上手快
# iproxy: usbmuxd 端口转发，真机调试

# 砸壳常用：frida-ios-dump（需越狱设备安装 Frida Server）
# 或使用已脱壳的 IPA（仅用于合法授权的分析）

    embedded.mobileprovision
