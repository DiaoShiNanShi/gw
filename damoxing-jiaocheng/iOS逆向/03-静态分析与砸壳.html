iOS 逆向 03：静态分析与砸壳

iOS 逆向模块

⚠️ 仅分析有授权的 IPA（自己的 App 或书面授权）。

学习目标：砸壳、class-dump、Hopper 看伪代码的基本流程。

1. 为什么要砸壳？

App Store 下载的 App，主二进制被苹果 FairPlay DRM 加密。直接 class-dump / Hopper 打开是乱码，需要先在运行时内存里 dump 出解密后的 Mach-O（砸壳）。

2. 砸壳流程（概念）

  1. 越狱设备安装 App，运行到内存解密
  2. 用 frida-ios-dump / clutch / dumpdecrypted 从内存导出 Mach-O
  3. 替换 IPA 里的原二进制 → 得到脱壳 IPA
# frida-ios-dump 示例（需配置 ios_ipa_dump 环境）
# python dump.py com.target.app
# 输出 save 目录下的脱壳 IPA

3. class-dump 导出头文件

class-dump -H YourApp -o headers/
# 得到所有 OC 类的 @interface 声明，快速了解 App 结构
# Swift 类名会被 mangled，需要 demangle 或看 Hopper

4. Hopper / IDA 静态分析

  1. 打开脱壳后的 Mach-O
  2. 看 Strings 窗口：常能发现 API URL、Key 变量名、调试日志
  3. 找 -[ClassName method:] 跟关键逻辑（登录、支付、AI 请求）
  4. 伪代码（F5）阅读算法流程

AI App 审计清单：
- Strings 里有没有 sk-、api_key、Bearer
- 是否硬编码 DeepSeek/OpenAI URL
- 证书校验是否可被 bypass

5. 加固与对抗（了解即可）

加固手段逆向难度
字符串加密Strings 搜不到 Key
代码混淆类名方法名无意义
反调试 ptrace附加 debugger 就退出
完整性校验改 binary 就 crash
