iOS 逆向 02：Hook 与动态调试（Frida / Method Swizzling）

iOS 逆向模块

⚠️ 仅用于学习和自己 App 的安全测试。Hook 他人 App 用于破解/盗刷属于违法行为。

学习目标：搞懂 Hook 原理，会用 Frida 做最基本的函数拦截。

1. Hook 是什么？（大白话）

Hook = 拦路虎。函数本来要执行 A 逻辑，你在中间插一脚，改成先执行你的代码 B，再决定是否继续 A。

方式原理典型场景
Method SwizzlingOC runtime 交换方法 IMP埋点、调试自己的 App
Fishhook改符号表，Hook C 函数拦截 printf、open 等
Frida注入 JS 引擎，动态插桩运行时改任意 App 逻辑（需越狱/调试权限）
Substrate/Cydia越狱插件框架系统级 Hook

2. Method Swizzling（开发里也会用）

// Swift 中常用 NSObject 子类 + @objc 方法 swizzle（仅调试/自家 App）
extension UIViewController {
    @objc func debug_viewDidAppear(_ animated: Bool) {
        print("[VC] \(type(of: self)) appeared")
        debug_viewDidAppear(animated)  // 调用原实现
    }
}
// 生产环境慎用 swizzle，App Store 审核对私有 API / 恶意 swizzle 敏感

// hook.js — 拦截 NSURLSession 请求 URL（学习用）
if (ObjC.available) {
    var className = "NSURLSession";
    var method = "- dataTaskWithRequest:completionHandler:";
    Interceptor.attach(ObjC.classes.NSURLSession[method].implementation, {
        onEnter: function(args) {
            var request = new ObjC.Object(args[2]);
            console.log("Request URL: " + request.URL().absoluteString());
        }
    });
}
