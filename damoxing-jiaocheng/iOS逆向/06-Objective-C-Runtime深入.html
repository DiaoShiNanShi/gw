iOS 逆向 06：Objective-C Runtime 深入

iOS 逆向模块

⚠️ 仅用于合法安全研究和自有 App 审计。

Method Swizzling、消息发送、元类的底层。

1. 消息发送

[obj doThing] → objc_msgSend(obj, @selector(doThing))。Runtime 查方法表找 IMP 执行。

2. 类结构

isa 指针 → 类对象 → 元类 → 根元类
方法列表 method_list → SEL + IMP
属性 protocol → 方法描述

3. Method Swizzling

Method m1 = class_getInstanceMethod(cls, @selector(viewDidLoad));
Method m2 = class_getInstanceMethod(cls, @selector(hook_viewDidLoad));
method_exchangeImplementations(m1, m2);

4. 逆向应用

找目标方法 SEL → 定位 IMP 地址 → Frida Hook 或 swizzle 替换。
