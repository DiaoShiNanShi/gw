iOS 逆向 08：加密、签名与证书链

iOS 逆向模块

⚠️ 仅用于合法安全研究和自有 App 审计。

Code Signing、Provisioning、HTTPS 证书锁定。

1. Code Signing

每个 App 有 embedded.mobileprovision + 签名。iOS 只运行信任链上的签名。

2. 证书类型

类型用途
Development开发调试
DistributionApp Store / Ad Hoc
Enterprise企业内部分发（滥用多）

3. HTTPS 与 SSL Pinning

Pinning = App 只信任指定证书，防中间人抓包。审计自己 App 时检查是否启用。

4. 常见加密

AES 对称加密存本地数据、RSA 非对称传密钥、Keychain 存密钥。逆向时找 CCCrypt/CommonCrypto 调用。
