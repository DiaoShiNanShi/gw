工作实战 16：Docker 与 K8s 部署入门

工作实战模块

企业级实战章节。

1. Docker 基础

FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

2. vLLM 容器

docker run --gpus all -p 8000:8000 vllm/vllm-openai \
  --model Qwen/Qwen2.5-7B-Instruct

3. K8s 核心概念

概念大白话
Pod最小部署单元
Deployment管 Pod 副本数
Service对内暴露端口
Ingress对外 HTTP 入口
HPA自动扩缩容

4. 何时上 K8s

QPS 高、要多副本、要 GPU 调度时。个人项目 Docker Compose 够用。
