工作实战 13：结构化输出与 JSON 模式

工作实战模块

企业级实战章节。

1. 为什么难

模型爱自由发挥，JSON 少括号、多字段是常态。

2. 解决方案

方案可靠性
Prompt 里写 Schema + 示例中
OpenAI JSON Mode高
Function Calling高
Outlines/Instructor 库高（约束解码）
后处理 + 重试兜底

3. Function Calling 示例

tools = [{"type":"function","function":{"name":"get_weather","parameters":{"type":"object","properties":{"city":{"type":"string"}},"required":["city"]}}}]
resp = client.chat.completions.create(model="gpt-4o", messages=msgs, tools=tools)

4. 校验重试模式

for attempt in range(3):
    raw = llm(prompt)
    try:
        data = json.loads(raw)
        validate(data, schema)
        break
    except: prompt += '\n上次格式错误，请严格输出 JSON'
