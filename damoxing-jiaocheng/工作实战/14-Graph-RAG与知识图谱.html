工作实战 14：Graph RAG 与知识图谱

工作实战模块

企业级实战章节。

1. 普通 RAG 的局限

切片丢失结构关系。「A 的老板的老婆的部门」这类多跳问题，向量检索常失败。

2. Graph RAG 思路

先建知识图谱（实体-关系），检索时走图遍历 + 向量，把子图喂给模型。

3. 流程

文档 → NER 抽实体 → 建关系 → 存图数据库(Neo4j)
提问 → 实体识别 → 图查询扩展 → LLM 生成

4. 工具

Microsoft GraphRAG、LlamaIndex KnowledgeGraph、Neo4j + LangChain。

5. 何时用

关系复杂、多跳推理、企业知识图谱已有基础时。简单 FAQ 用普通 RAG 就够。
