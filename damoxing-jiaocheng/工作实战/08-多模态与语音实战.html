工作实战 08：多模态与语音实战（看图、听声、说话）

工作实战模块

学习目标：搞懂「能看图、能听声、能说话」的 AI 怎么用。
大白话：以前 AI 只认字，现在还能认图、认声音——多模态就是「多种感官」。

1. 多模态是什么？（一张表看懂）

模态输入输出典型模型/API
纯文本文字文字GPT-4、DeepSeek、Qwen
视觉理解图片+文字文字GPT-4o、Qwen-VL、Gemini
语音输入音频文字Whisper、Apple Speech
语音输出文字音频TTS API、AVSpeechSynthesizer

企业场景：拍照识物、票据 OCR、语音客服、会议纪要、视频内容理解。

2. 视觉 API 实战（Python，OpenAI 兼容）

# vision_demo.py — 让 AI「看」一张图并描述
import base64
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

# 本地用 llava 等多模态模型：ollama pull llava
with open("photo.jpg", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()

resp = client.chat.completions.create(
    model="llava",  # 或 gpt-4o / qwen-vl-max
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "这张图里有什么？用中文简短描述。"},
            {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{b64}"}}
        ]
    }]
)
print(resp.choices[0].message.content)

注意：图片越大 Token 越贵，生产环境先压缩到 1024px 以内。

3. iOS 端多模态（Swift 思路）

// 拍照 → 转 Base64 → 调多模态 API
import UIKit

func imageToBase64(_ image: UIImage) -> String? {
    guard let data = image.jpegData(compressionQuality: 0.7) else { return nil }
    return data.base64EncodedString()
}

// UIImagePickerController 选图 → base64 → 和你的 AIClient 一样 POST
// 端侧纯本地视觉：Vision 框架做人脸/文字检测；复杂理解仍走云端或 Core ML 自定义模型

4. 语音：Whisper 转文字 + TTS 播报

# 语音转文字（OpenAI Whisper API 或本地 faster-whisper）
# pip install openai
from openai import OpenAI
client = OpenAI()

with open("meeting.mp3", "rb") as audio:
    transcript = client.audio.transcriptions.create(model="whisper-1", file=audio)
print(transcript.text)

iOS 本地方案：Speech 框架识别 + AVSpeechSynthesizer 播报，不花钱、可离线，精度略低于云端 Whisper。

5. 多模态 RAG（文档里有图怎么办？）

  1. OCR 提取文字 → 和普通 RAG 一样入库（最简单）
  2. 多模态 Embedding → 图片也向量化，和文字一起检索（CLIP 类模型）
  3. 图片描述 → 先用视觉模型生成文字描述，再存向量库

示例：产品手册 PDF 里有大量示意图 → 先 OCR + 视觉模型补描述 → 切片 → RAG。

小结

  1. 多模态 = 不止文字，还有图、声
  2. 视觉/语音大多走 API；iOS 本地用 Speech + Vision 做轻量场景
  3. 文档 RAG 遇到图：OCR 或「先描述再入库」
