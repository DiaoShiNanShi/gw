工作实战 02：大模型 API 对接（把 AI 接进你的产品）

工作实战模块

学习目标：掌握对接大模型 API 的完整技能：选哪家、怎么调、流式输出、成本控制、生产级错误处理。
这是 AI 应用开发的第一行代码，也是工作中最高频的技能。

1. API 是什么（大白话）

API = 一家公司把模型能力打包成一个"电话"，你打过去说一句话（请求），那边回一句话（响应）。

你的产品 → 发 HTTP 请求（带问题）→ 大模型公司的服务器 → 返回回答

2. 主流 API 选型（2026 年实用版）

厂商 模型 特点 价格（约）
DeepSeek deepseek-chat / deepseek-reasoner 国产性价比之王，推理强 极便宜，几乎白菜价
阿里通义 qwen-max / qwen-plus 中文好，阿里生态 中档
OpenAI GPT-4o / GPT-4.1 综合最强，工具调用稳 贵

选择建议：
- 国内产品（合规要求）：DeepSeek / 通义 / 豆包 / 智谱（国内直连，不需要翻墙）
- 个人学习练手：DeepSeek（便宜 + 强）
- 追求效果不差钱：OpenAI GPT-4o

关键知识点：国内主流 API 全部兼容 OpenAI 的接口格式——代码几乎可以无缝切换，学会一个就会全部。

3. 第一个 API 调用（Python）

# 需要先注册 DeepSeek 开放平台拿 API Key（https://platform.deepseek.com）
# 安装：pip install openai

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的key",          # 换成你的
    base_url="https://api.deepseek.com",  # 换成对应厂商
)

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是资深 iOS 架构师，回答简洁专业。"},
        {"role": "user", "content": "Swift 中 @MainActor 是干什么的？"},
    ],
    temperature=0.7,
)

print(resp.choices[0].message.content)

Message 结构（理解这个就理解所有 API）：

role 含义 例子
system 系统设定（人设/规则） "你是客服，不说废话"
user 用户说的话 "怎么退款？"
assistant AI 之前说的话 "请问您的订单号是？"（多轮对话时回传）

多轮对话的核心技巧：把历史消息全部塞进 messages 数组，模型就能"记住"上下文。
注意：消息越多，token 费越高、速度越慢，所以要"滑动窗口"只保留最近 N 轮。

4. 流式输出（SSE）——生产环境必用

为什么必须用流式？ 非流式要等模型生成完一整段才返回，用户干等 5~20 秒，体验极差。流式是"生成一个字推一个字"，用户 0.5 秒就看到响应。

from openai import OpenAI

client = OpenAI(api_key="sk-你的key", base_url="https://api.deepseek.com")

stream = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "写一首关于秋天的诗"}],
    stream=True,          # ← 开启流式
)

for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)  # 一个字一个字打印

前端配合：后端用 SSE（Server-Sent Events）转发，前端用 EventSource 或 fetch 读流，实现打字机效果。

5. 关键参数详解（生产配置）

参数 含义 生产建议
temperature 随机性 客服/代码 0.1~0.3；创意 0.8~1.0
max_tokens 回答最大长度 按需设，防止 AI 话痨烧钱
top_p 候选范围 一般用默认，和 temperature 二选一调
stream 是否流式 聊天场景必须 true
response_format 强制 JSON {"type": "json_object"}
messages 对话历史 记得做滑动窗口裁剪

6. 生产级代码模板（抄这个就够）

"""
生产级 LLM 调用封装：重试 + 限流 + 错误处理 + 成本打印
"""
import time, json
from openai import OpenAI
from tenacity import retry, stop_after_attempt, wait_exponential

client = OpenAI(api_key="sk-你的key", base_url="https://api.deepseek.com")

def count_tokens(text):
    """粗略估算 token 数（中文约 1 字≈1 token，英文 4 字符≈1 token）"""
    return len(text) // 2 + 1

@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=1, max=10))
def chat(messages, temperature=0.3, max_tokens=1024, json_mode=False):
    """带重试的对话函数：网络抖动/限流会自动重试 3 次"""
    try:
        kwargs = {"temperature": temperature, "max_tokens": max_tokens}
        if json_mode:
            kwargs["response_format"] = {"type": "json_object"}
        resp = client.chat.completions.create(
            model="deepseek-chat", messages=messages, **kwargs
        )
        content = resp.choices[0].message.content
        # 打印成本（deepseek 单价约 输入0.014元/千token，输出0.028元/千token）
        usage = resp.usage
        cost = usage.prompt_tokens / 1000 * 0.014 + usage.completion_tokens / 1000 * 0.028
        print(f"[成本] 输入{usage.prompt_tokens}token + 输出{usage.completion_tokens}token ≈ {cost:.4f}元")
        return content
    except Exception as e:
        print(f"[错误] {e}")
        raise

# 使用示例：JSON 模式
def extract_info(text):
    result = chat([
        {"role": "system", "content": "提取信息，返回 JSON：{姓名, 电话, 意向}"},
        {"role": "user", "content": text},
    ], json_mode=True)
    return json.loads(result)

# 使用示例：多轮对话（带历史裁剪）
def multi_turn(new_user_msg, history, max_rounds=10):
    history.append({"role": "user", "content": new_user_msg})
    history = history[-max_rounds*2:]  # 只保留最近 10 轮
    reply = chat(history)
    history.append({"role": "assistant", "content": reply})
    return reply, history

7. 成本控制（老板最关心的）

Token 计价逻辑：输入 + 输出都花钱，输出比输入贵。

省钱手段 说明
模型降级 简单任务用便宜的 deepseek-chat，别用 reasoning 模型
消息裁剪 只传最近 N 轮对话
Prompt 精简 System Prompt 越短越省（每轮都计费！）
缓存 相同问题用 Redis 缓存结果
限流 给用户限次（如每天 50 次免费额度）
批量 离线任务用 batch API（半价）

真实账本（感受一下）：
- DeepSeek 输出约 0.028 元/千 token
- 一次普通客服问答约 500 token 输出 → 约 0.014 元/次
- 1 万次日活 × 0.014 元 ≈ 每天 140 元 → 每月约 4200 元
- 对比：GPT-4o 同规模每月要 10 万+ 元

8. 常见坑与排查

现象 原因 解决
401 错误 API Key 错了/过期 检查 key；环境变量别硬编码进代码
429 错误 触发限流 加重试 + 退避（上面模板已处理）
400 错误 参数格式不对 检查 messages 结构
回答被截断 max_tokens 太小 调大
输出格式不对 模型没守规矩 开 json_mode + 提示词强化
中文乱码 编码问题 确保 HTTP 头 UTF-8

安全红线（重要）：
- API Key 绝不写进前端代码（会被扒走盗刷）
- 服务端转发，前端永远不直接调大模型 API
- 用户输入做敏感词/隐私过滤再进模型
- 合规：国内产品必须用国内备案的 API 服务
