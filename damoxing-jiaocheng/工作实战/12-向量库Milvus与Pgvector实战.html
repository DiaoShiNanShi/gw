工作实战模块

企业级实战章节。

1. Chroma → 生产的鸿沟

Chroma 适合开发；上线要考虑并发、持久化、备份、权限。

2. pgvector 方案

向量存在 PostgreSQL 里，和业务数据同库。SQL 过滤 + 向量检索一次搞定。

-- 创建向量列
ALTER TABLE documents ADD COLUMN embedding vector(1536);
CREATE INDEX ON documents USING hnsw (embedding vector_cosine_ops);

-- 混合检索
SELECT content FROM documents
WHERE category = '人事'
ORDER BY embedding <=> query_vector
LIMIT 5;

3. Milvus 方案

独立向量服务，支持亿级、多租户、云原生。Docker 一键起。
