工作实战 19：iOS Core ML 模型部署专章

工作实战模块

企业级实战章节。

1. Core ML 是什么

苹果官方端侧推理框架，自动用 CPU/GPU/ANE（神经引擎）。

2. 转换流程

PyTorch/ONNX → coremltools → .mlpackage → 拖进 Xcode → Swift 调用

3. Swift 调用

import CoreML
let model = try MyClassifier(configuration: MLModelConfiguration())
let input = MyClassifierInput(text: "hello")
let output = try await model.prediction(input: input)

4. LLM 注意

Core ML 更适合分类/检测小模型。大 LLM 目前 llama.cpp/MLX 更成熟；Apple Foundation Models 是 iOS 26+ 新选项。

5. ANE 优化

  • 模型算子要 ANE 支持
  • 固定输入 shape 更好
  • Instruments 看 ANE 利用率
