中级 06：损失函数与优化器（模型怎么「学会」）

中级模块

训练 = 不断算损失、反向传播、更新参数。这章讲底层数学直觉。

1. 损失函数（Loss）

预训练：交叉熵损失——预测下一个 token 和真实 token 差多少。

大白话：猜错了扣分，猜对了加分，模型拼命减分。

2. 反向传播

从输出层往回算每个参数对 Loss 的「责任」（梯度），链式法则一层层传。

3. 优化器

优化器特点
SGD最原始，慢
Adam自适应学习率，最常用
AdamW加权重衰减，大模型标配

4. 学习率

太大 → Loss 炸（NaN）；太小 → 训不动。常用 warmup + cosine decay。

5. 你需要记住的

训练 = 前向算 Loss → 反向算梯度 → 优化器更新参数 → 重复几万亿次。
