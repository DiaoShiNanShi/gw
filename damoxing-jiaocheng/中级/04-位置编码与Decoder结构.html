中级 04：位置编码与 Decoder 结构

中级模块

模型怎么知道词序？Decoder 怎么做到只往右生成？

1. 为什么需要位置编码

Attention 本身不区分顺序，「狗咬人」和「人咬狗」算出来一样。必须注入位置信息。

2. 位置编码方案

方案特点现状
绝对位置sin/cos 函数老方案
RoPE 旋转位置相对位置，外推好Llama/Qwen 主流
ALiBi线性偏置部分长上下文模型

3. Decoder-only 结构

输入 Token → Embedding + 位置编码
    ↓
[N × Decoder Block]
  每个 Block = Masked Attention + FFN + Norm
    ↓
输出 logits → Softmax → 采样下一个 Token
    ↓
拼到输入，循环…

4. Masked Attention（因果掩码）

生成第 5 个 token 时，只能看 1~4，不能偷看 6~N。用一个三角矩阵把「未来」遮掉。
