中级 05：对齐技术（SFT / RLHF / DPO 一条线讲清）

中级模块

预训练让模型「会说话」，对齐让模型「说人话、听指令」。

1. 三阶段全景

预训练（读万卷书）→ SFT（学会听指令）→ RLHF/DPO（学会讨人喜欢）

2. SFT 监督微调

数据：「用户问题 → 理想回答」对，几千~几万条就够起步。

作用：从「续写」变成「问答」。

3. RLHF

  1. 训练奖励模型（人打分好/坏回答）
  2. 用 PPO 强化学习，让模型拿高奖励

缺点：流程复杂、训练不稳定、贵。

4. DPO / GRPO

DPO：直接对比好答案和坏答案，不用单独训奖励模型。

GRPO：DeepSeek R1 用的，组内采样对比，更稳。

5. 你需不需要微调？

场景建议
通用问答Prompt + RAG 够了
特定格式/语气SFT 或 DPO
私有领域知识RAG 优先，不够再 Continue PT
资源有限LoRA，别全参
