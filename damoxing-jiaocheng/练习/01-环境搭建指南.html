练习 01：环境搭建指南（按你的 Mac M2 16GB 量身定制）

练习模块

你的配置：Apple M2 / 8 核 CPU / 16GB 统一内存 / 10 核 GPU / macOS 26.5.2 / 磁盘可用约 17GB
这套搭建方案保证：装完能跑 7B 以内的本地模型，能做 RAG、微调等全部基础项目。

0. 动手前先做一件事：清理磁盘空间

你的磁盘只剩约 17GB 可用，而大模型文件动辄几 GB。先腾出空间，否则装到一半会失败。

# 查看磁盘占用
df -h /
# 看看哪些文件夹最占空间
du -sh ~/Downloads ~/Movies ~/Library/Caches 2>/dev/null
# 清理 Homebrew 缓存（如果装了）
brew cleanup --prune=all 2>/dev/null
# 清理 pip/conda 缓存
rm -rf ~/Library/Caches/pip 2>/dev/null

目标：腾出 30GB 以上可用空间（模型 10GB + 环境 5GB + 项目数据 5GB + 余量）。

1. 方案总览（三选一，按你的目标选）

方案 装什么 适合谁 难度
A. 零代码方案 只装 LM Studio（图形界面） 只想玩、不想写代码 ⭐
B. 新手完整方案（推荐） Ollama + Python + 向量库 想学原理也想动手 ⭐⭐
C. 开发者进阶方案 MLX + llama.cpp + conda 想做正经 AI 开发 ⭐⭐⭐

建议：先装 B（Ollama 5 分钟跑起第一个模型），再装 C 的 MLX 做进阶项目。

2. 方案 A：LM Studio（零代码，10 分钟）

  1. 打开浏览器访问 https://lmstudio.ai 下载 macOS 版（Apple Silicon 版）
  2. 拖入「应用程序」文件夹，首次启动按提示安装命令行工具
  3. 顶部搜索框搜模型名，如 Qwen2.5 7B，选 Q4_K_M 版本下载（约 4.5GB）
  4. 下载完点击模型 → 加载 → 开始聊天

适合场景：纯体验、测试不同模型效果。缺点：不方便做二次开发。

3. 方案 B：Ollama + Python（新手推荐，30 分钟）

第 1 步：安装 Ollama（一键脚本）

# 安装 Ollama（自动装到 /usr/local 或 ~/.ollama）
curl -fsSL https://ollama.com/install.sh | sh

验证：

ollama --version

第 2 步：拉取第一个模型（按你配置选一个）

# 推荐按顺序尝试（从最小的开始，逐步升级）
ollama run qwen2.5:0.5b    # 400MB，秒下，先体验
ollama run qwen2.5:1.5b    # 1GB，流畅，适合日常
ollama run qwen2.5:7b      # 4.7GB，你的配置上限附近，最聪明
ollama run llama3.2:3b     # 2GB，Meta 的模型，英文更强

注意：ollama run 第一次会下载模型，下载完自动进入聊天界面，输入 /bye 退出。

你的 16GB 内存建议常驻 1.5B 或 3B，7B 也能跑但会吃满内存（其他应用会卡）。

第 3 步：测试模型列表

ollama list          # 查看已下载模型
ollama ps            # 查看当前加载的模型
ollama rm 模型名      # 删除模型（省磁盘）

第 4 步：安装 Python 开发环境

macOS 自带 Python3，但建议用 miniconda（管理环境最省心）：

# 安装 miniconda（Apple Silicon 版）
curl -fsSL https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh -o /tmp/miniconda.sh
bash /tmp/miniconda.sh -b -p $HOME/miniconda3
$HOME/miniconda3/bin/conda init zsh
# 重开终端后：
conda create -n llm python=3.11 -y
conda activate llm

为什么用 conda？ 以后装 PyTorch、向量数据库等 AI 库，环境隔离最不容易出兼容问题。

第 5 步：安装 AI 常用库

conda activate llm
pip install openai chromadb sentence-transformers

（openai 库是用来调 Ollama 的 API 的，Ollama 兼容 OpenAI 接口，见项目实战）

4. 方案 C：MLX（Apple Silicon 进阶，15 分钟）

MLX 是苹果官方 AI 框架，你的 M2 跑它比 PyTorch 快且省内存，进阶开发必装。

conda activate llm
pip install mlx mlx-lm

验证并跑通：

# 用 MLX 跑 Qwen2.5-1.5B（首次自动下载模型）
python -m mlx_lm.generate --model Qwen/Qwen2.5-1.5B-Instruct-4bit --prompt "用一句话介绍你自己"

MLX 也能当 API 服务用：

python -m mlx_lm.server --model Qwen/Qwen2.5-7B-Instruct-4bit --port 8080
# 另开终端测试
curl http://localhost:8080/v1/chat/completions -H "Content-Type: application/json" -d '{"messages":[{"role":"user","content":"你好"}]}'

顺手装 llama.cpp（可选，极客玩家）

brew install llama.cpp
# 跑 GGUF 模型（需要自己先下载 .gguf 文件）
llama-cli -m ~/models/qwen2.5-1.5b-q4.gguf -p "你好"

5. 模型选择推荐表（M2 16GB）

用途 模型 大小 说明
手机级体验 Qwen2.5-0.5B 0.4GB 秒加载，练手
日常聊天/问答 Qwen2.5-1.5B 1GB 流畅 + 聪明，日常主力
写代码辅助 Qwen2.5-Coder-3B 2GB 代码能力在同级最强
中文最强 7B Qwen2.5-7B 4.7GB 你的配置上限，吃满内存
英文/通用 Llama 3.2-3B 2GB Meta 官方，英文好
英文小模型 Llama 3.2-1B 0.7GB 极快

记住经验法则：模型文件大小 ≤ 内存 1/3（16GB → 模型别超 5GB）。

6. 常见问题速查

问题 解决办法
磁盘满了 ollama list 看装了啥，ollama rm 删不用的模型
跑大模型卡死 换小一号模型；关闭其他大型应用
ollama 命令找不到 重开终端；或 source ~/.zshrc
下载模型超时 换网络环境；或挂代理后 export HTTPS_PROXY=...
想用中文 首选 Qwen 系列（国产，中文语料多）
