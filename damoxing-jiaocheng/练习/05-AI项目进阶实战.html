练习 05：AI 项目进阶实战（6 个中级项目）

练习模块

基础 5 个项目做完后，用这 6 个进阶项目练企业级能力。

项目 6：企业文档 RAG

PDF + Word 入库，混合检索 + Rerank，Web 问答界面。技术：LangChain + Chroma + FastAPI。

项目 7：Agent 自动写周报

Function Calling 调日历/邮件 API，自动汇总生成周报。技术：OpenAI tools + Python。

项目 8：模型评测流水线

50 条测试集 + 自动跑分 + 报告。技术：Python + pytest。

项目 9：语义缓存服务

Redis + embedding 相似度，命中缓存直接返回。技术：FastAPI + sentence-transformers。

项目 10：Docker 部署 vLLM

GPU 云服务器 Docker 起 vLLM，OpenAI 兼容接口对外服务。

项目 11：iOS 语音 AI 助手

SwiftUI + Speech + 云端 API + TTS 完整闭环。
