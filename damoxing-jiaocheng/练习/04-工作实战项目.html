练习 04：工作实战项目（企业级大项目，面试作品集）

练习模块

学习目标：把「工作实战」模块的技能串起来，做出 3 个拿得出手的企业级项目。
这 3 个项目做完，你可以写进简历，面试时随便深挖都能聊。

项目 6：企业知识库问答机器人（RAG 完整落地）

难度：⭐⭐⭐⭐ 耗时：2~3 天
技能点：RAG + API + 后端 + 前端

需求

做一个"公司制度问答机器人"：上传 PDF/Word 文档，用户提问，机器人基于文档回答并标注来源。

技术栈

  • 后端：FastAPI
  • 向量库：ChromaDB（本地）→ 可换 Milvus
  • Embedding：bge-m3 或 nomic-embed-text
  • LLM：DeepSeek API 或本地 Ollama
  • 前端：简单 HTML 页面即可

功能清单

✅ 上传文档（PDF/Word/TXT）
✅ 文档入库（切分 + 向量化）
✅ 问答（检索 + 生成 + 引文标注）
✅ 管理页面（看已入库文档、删除）
✅ 效果优化：查询改写 + 混合检索 + Rerank

验收标准

1. 上传 3 份你熟悉的文档（如《大模型学习教程》里的章节）
2. 问 5 个文档里有明确答案的问题 → 全部答对且带出处
3. 问 2 个文档里没有的问题 → 机器人说"资料中未提及"而不是瞎编

加分项

  • 接入企业微信/钉钉机器人（企微群 @机器人 提问）
  • 权限控制（不同用户只能查自己部门的文档）
  • 流式输出打字机效果

项目 7：AI 工作流助手（Agent + Function Calling）

难度：⭐⭐⭐⭐⭐ 耗时：3~5 天
技能点：Agent + Function Calling + 工具设计 + 安全

需求

做一个"运营助理 Agent"：用户用自然语言下指令，Agent 自动完成多步操作。

功能清单

✅ 工具 1：查天气（天气 API）
✅ 工具 2：查/记日程（本地 JSON 存储）
✅ 工具 3：生成文案（LLM）
✅ 工具 4：发邮件（smtplib，先模拟）
✅ 多步任务："帮我看明天北京的天气，如果下雨就生成一条带伞提醒文案，并记到日程里"
✅ 最大轮数限制 + 日志记录

验收标准

输入："帮我查北京后天天气，超过 30 度就生成防晒提醒，记到日程"
观察 Agent 是否自动：
1. 调用天气工具
2. 判断条件（>30 度）
3. 生成提醒文案
4. 调用日程工具写入
全程不需要你手动分步

加分项

  • 用 Dify 拖一个可视化版本对比体验
  • 接 MCP：写一个自己的 MCP server（查数据库）
  • 加"确认环节"：危险操作（发邮件）先问用户

项目 8：iOS AI 聊天 App（原生 AI 应用）

难度：⭐⭐⭐⭐ 耗时：3~5 天
技能点：Swift + SwiftUI + API + 上架意识（结合你的主业）

需求

做一个功能完整的 iOS AI 聊天 App，上架思路清晰。

功能清单

✅ 聊天界面（气泡、流式打字机效果、自动滚动）
✅ 多轮对话（历史消息管理）
✅ System Prompt 设置页（用户可自定义人设）
✅ 温度调节（滑杆控制随机性）
✅ 历史会话列表（本地存储）
✅ 深色模式适配

验收标准

1. App 能流畅聊天（流式输出）
2. 修改人设后行为立即变化
3. 杀 App 重开能恢复历史会话
4. 写清楚 PrivacyInfo.xcprivacy 和隐私政策文案

加分项

  • 加语音输入（Speech 框架）
  • 加图片理解（多模态 API，拍照提问）
  • 加端侧降级：断网时用本地小模型兜底（llama.cpp）
  • 完整走一遍"功能清单 → 上架文档"流程，形成上架 Checklist

项目 9（挑战）：本地 LLM 聊天 App（端侧模型集成）

难度：⭐⭐⭐⭐⭐⭐ 耗时：1~2 周
技能点：llama.cpp / MLX Swift + 原生开发（你之前的 ITPhone 就是这个路线）

需求

做一个完全离线可用的 AI 聊天 App，模型打包或首次下载。

功能清单

✅ 集成 llama.cpp（或 MLX Swift）
✅ 内置 Qwen2.5-0.5B / 1.5B 量化模型
✅ 流式生成（逐 token 显示）
✅ 设备信息注入（类似 ITPhone 的最简 RAG）
✅ 三级降级：本地模型 → Apple FoundationModels（iOS 26+）
✅ 性能监控：显示 token/秒

加分项

  • 模型商店（从 HuggingFace 下载不同模型）
  • 对话历史导出
  • App 瘦身（模型分包下载）

项目组合建议（简历怎么写）

项目 简历描述方向
项目 6 知识库问答 "负责企业知识库 RAG 系统，支持文档上传与溯源问答"
项目 7 Agent "设计多工具 Agent 工作流，支持自然语言驱动的多步任务"
项目 8/9 iOS App "独立开发 iOS AI 应用，实现流式对话与端侧模型集成"

如果只想做 2 个：项目 6（RAG）+ 项目 8（iOS）——覆盖面最广，一个是后端 AI 落地，一个是前端原生应用。

做项目的通用方法论（避坑指南）

  1. 先跑通再优化：第一版全用最简实现（本地 Ollama + 单文件脚本），跑通流程再上生产组件
  2. 写 README：项目做完写 README（架构图 + 运行步骤 + 技术决策），面试官第一眼看这个
  3. 录演示视频：30 秒演示视频放 GitHub，效果远超文字
  4. 记录踩坑：遇到的 bug 和解决过程写进文档，面试时"你遇到最难的问题是什么"就有素材了
  5. 部署上线：至少一个项目部署到云服务器（哪怕是最便宜的），简历写"已上线"
