进阶 07：JTAG 与 SWD 调试

进阶

ST-Link/J-Link 断点、单步、Watch 变量。

1. SWD 线

SWDIO / SWCLK / GND / 3.3V — 4线调试

2. CubeIDE

Debug As → STM32 C/C++ Application → 断点 F5 继续 F6 单步。

3. OpenOCD

openocd -f interface/stlink.cfg -f target/stm32f1x.cfg

4. vs 串口
