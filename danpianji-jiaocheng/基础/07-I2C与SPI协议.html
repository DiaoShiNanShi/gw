基础 07：I2C 与 SPI 协议

基础模块

学习目标：搞懂两种最常用的"芯片间对话"协议。

1. 为什么需要协议？

一个 MCU 要同时连屏幕、传感器、存储器——各用各的线太乱。I2C 和 SPI 就是标准化的接线+说话规则。

2. I2C：两线走天下

     MCU                    传感器A    传感器B
  SDA ─┬──────────────────────┬──────────
  SCL ─┴──────────────────────┴──────────
       (只需要 2 根线，可挂 127 个设备)
特点说明
线数2 根（SDA 数据 + SCL 时钟）
速度100K / 400K / 1M
优点省引脚，多设备
缺点速度较慢
常见设备OLED 屏、温湿度 SHT30、加速度计 MPU6050、EEPROM

代码示例：读 I2C 温湿度

#include <Wire.h>
#include <Adafruit_SHT31.h>
Adafruit_SHT31 sht31 = Adafruit_SHT31();

void setup() {
    sht31.begin(0x44);  // I2C 地址 0x44
}
void loop() {
    float t = sht31.readTemperature();
    float h = sht31.readHumidity();
    Serial.printf("T=%.1f H=%.1f\n", t, h);
    delay(2000);
}

3. SPI：速度之王

特点说明
线数4 根（MOSI + MISO + SCK + CS）
速度可达 80MHz
优点快！适合屏幕、Flash
缺点线多，每个设备要一根 CS
常见设备TFT 彩屏、SD 卡、W25Q Flash、LoRa 模块

4. 怎么选？

场景推荐
多个传感器I2C
屏幕/Flash/高速SPI
和 PC/模块通信UART
和手机通信BLE
远程/云端Wi-Fi + MQTT
