1. 协议速查表

协议线数距离典型场景
UART（串口）2（TX/RX）短调试打印、GPS 模块
I2C2（SDA/SCL）短温湿度、OLED 屏

BLE无线10m 内手环、iOS 联动 ⭐
Wi-Fi无线远智能家居、MQTT
MQTT基于 TCP互联网设备 ↔ 云端 ↔ App

2. 和 iOS 的关系

  • BLE → CoreBluetooth（你最该先学的）
  • Wi-Fi + MQTT → App 通过云端控制设备
  • HTTP → ESP32 开 Web Server，App 直接请求

3. 大白话记忆

  • UART = 两个人面对面说话（调试必备）
  • I2C = 一条总线挂多个设备（像 USB Hub）
  • BLE = 蓝牙，和 iPhone 配对
