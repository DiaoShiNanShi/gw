2. 嵌入式必学：指针与位操作

// 读寄存器：把地址 0x4001080C 当作 int 指针，写入 1 点亮 LED
*(volatile unsigned int *)0x4001080C = 0x01;

// 位操作：置位第 5 位
GPIOA->ODR |= (1 << 5);   // 点亮
GPIOA->ODR &= ~(1 << 5);  // 熄灭

Swift 里你很少碰指针，嵌入式里每天都在碰。
