基础 08：位操作与寄存器

基础模块

掌握位与/或/异或/移位，读写寄存器配置外设。

要点说明
实验DevKit 验证
调试串口 printf

1. 位操作符

// 置位第5位
reg |= (1 << 5);
// 清位
reg &= ~(1 << 5);
// 翻转
reg ^= (1 << 5);
// 读位
if (reg & (1 << 3)) { ... }

2. 寄存器结构体

typedef struct {
    volatile uint32_t MODER;   // 模式
    volatile uint32_t ODR;     // 输出
} GPIO_TypeDef;
#define GPIOA ((GPIO_TypeDef *)0x40010800)

3. HAL 封装

HAL_GPIO_WritePin 底层仍是位操作。调试到底层时需看 Reference Manual 寄存器定义。

4. 位域 struct

typedef struct {
    uint32_t mode  : 2;
    uint32_t type  : 1;
    uint32_t res   : 29;
} GPIO_MODER_Bits;
💡 位操作是寄存器配置日常，类似 Swift OptionSet。

常见问题

为何不用乘除?

移位比乘除快，编译期可优化。

HAL vs 寄存器?

HAL 可移植，寄存器高效/debug。

位域 portable?

依赖编译器/endian，MCU 常用宏。
