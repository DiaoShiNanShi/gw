基础 08：工具链与环境搭建

基础模块

1. ESP32 路线（推荐首选）

# 安装 Arduino IDE 或 VS Code + PlatformIO
# Mac 串口查看
ls /dev/cu.*          # 找到 usbserial 设备
screen /dev/cu.usbserial-xxx 115200   # 看串口输出

2. STM32 路线（求职向）

  1. 下载 STM32CubeIDE（免费）
  2. 用 ST-Link 连接电脑
  3. CubeMX 图形化配置引脚 → 生成代码

3. 调试工具箱

工具用途
串口监视器看 printf 调试信息
万用表测电压、通断
逻辑分析仪看 I2C/SPI 波形
示波器看信号质量（进阶）
💡 第一天的目标：环境装好 → 例程编译通过 → 串口看到 "Hello" → LED 闪起来。搞定这四步就算入门。
