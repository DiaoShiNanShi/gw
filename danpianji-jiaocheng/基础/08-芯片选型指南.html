基础模块

学习目标：知道什么项目用什么芯片，不花冤枉钱。

2. iOS 开发者推荐路线

第一步：ESP32（Arduino 框架） → 快速出成果，Wi-Fi + BLE 都有
第二步：ESP32（ESP-IDF） → 专业 FreeRTOS 开发
第三步：STM32 → 工业级，求职必备
全程：iOS App 做控制端 → 你的核心竞争力

3. 选型决策树

需要联网吗？
├─ 是 → 需要 BLE 吗？
│       ├─ 是 → ESP32 ✅（最推荐）
│       └─ 否 → ESP8266（省钱）
└─ 否 → 需要高性能吗？
        ├─ 是 → STM32H7 / RP2040
        └─ 否 → STM32F103 / Arduino
