硬件 03：原理图阅读入门

硬件入门

读原理图定位引脚，符号识别，四步阅读法。

1. 为何重要

原理图 = 硬件 API 文档。不知道 GPIO2 接什么，代码写对也白搭。

2. 符号

符号含义
R电阻
C电容
D/LED二极管/LED
U芯片
VCC/GND电源地

3. 四步阅读

1.找MCU芯片 2.看电源树(LDO/去耦) 3.跟GPIO到外围 4.看通信(UART/I2C)

4. 获取途径

厂商 GitHub/Wiki、立创EDA 开源、DevKit PDF 随板附赠。

💡 PDF 对照实物板最快建立空间感。
