硬件 03：原理图阅读入门

硬件入门

1. 为什么要看原理图？

做 iOS 要看 API 文档，做硬件要看原理图。它告诉你每个引脚连了什么、电源怎么走的。

2. 常见符号

符号含义
—▷|—二极管/LED（箭头方向是电流方向）
—/\/\/\—电阻
—||—电容
VCC / 3V3电源正极
GND ⏚地（零电位参考）

3. 阅读顺序

  1. 找 MCU 芯片（中心位置，引脚最多）
  2. 看 电源部分（VCC → 稳压 → 3.3V）
  3. 看 MCU 引脚连了什么（LED→PC13, 按键→PA0…）
  4. 看 通信接口（I2C 传感器、SPI 屏幕）
💡 推荐工具：立创 EDA（免费在线画/看原理图）、LCSC 商城（买元件）
