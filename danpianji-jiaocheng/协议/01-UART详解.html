协议 01：UART 详解

协议模块

UART 帧格式、波特率、接线、ESP32/STM32 收发。

1. 基础

参数典型值
波特率115200
数据位8
停止位1
校验None

2. 接线

MCU TX → 模块 RX
MCU RX → 模块 TX
GND 必须共地

3. ESP32 代码

Serial.begin(115200);
Serial.printf("Chip: %s\n", ESP.getChipModel());
while(Serial.available()) {
  char c = Serial.read();
  Serial.write(c); // echo
}

4. 应用

调试 NSLog 级、GPS NMEA、蓝牙 AT 指令、Modbus RTU 物理层。

💡 TX/RX 交叉，必须共 GND。

常见问题

乱码?

波特率不一致。

USB-TTL?

无 USB 的板子需要。

printf 重定向?

_write 或 HAL_UART_Transmit。

本章小结

  • UART两线全双工
  • 115200最常用
  • TXRX交叉共地
  • 嵌入式NSLog
