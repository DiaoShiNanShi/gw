STM32 09：定时器与 PWM

STM32 专题

TIM PWM 模式，频率占空比，舵机/电机。

要点说明
实验DevKit 验证
调试串口 printf

1. PWM 公式

freq = TIM_CLK / ((PSC+1)*(ARR+1))
duty = (CCR+1)/(ARR+1)

2. 启动

HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, 750); // 75% duty

3. 舵机 50Hz

ARR 定 20ms 周期，CCR 1-2ms 脉宽。

4. 输入捕获

测外部脉冲宽度，超声波/编码器。

💡 高级定时器 TIM1/8 可驱动电机互补 PWM+死区。

常见问题

PSC ARR?

预分频与自动重装。

互补输出?

H桥电机。

编码器模式?

TIM 硬件解码。
