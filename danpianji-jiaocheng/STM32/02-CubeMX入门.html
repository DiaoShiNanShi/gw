STM32 02：CubeMX 入门

STM32 专题

图形化配时钟/GPIO/UART，生成工程。

1. 流程

  1. 选芯片/NUCLEO
  2. Pinout 点引脚
  3. Clock 配 PLL
  4. Project→Generate

2. 引脚配置

模式用途
GPIO_OutputLED
GPIO_EXTI按键
USART1串口
I2C1传感器

3. 生成目录

Core/Src/main.c — 用户代码区 USER CODE BEGIN/END
Drivers/ — HAL 库
.ioc — 可重新打开 CubeMX

4. 规则

只在 USER CODE 区写逻辑，避免 regenerate 覆盖。

💡 改 .ioc 重新 Generate，别手改 generated 文件。

常见问题

覆盖代码?

写 USER CODE 区内。

时钟红叉?

PLL 倍频超规格。

HAL vs LL?

HAL 易用 LL 高效。

本章小结

  • CubeMX 配引脚时钟
  • Generate 生成 HAL
  • USER CODE 区写逻辑
  • .ioc 可版本管理
