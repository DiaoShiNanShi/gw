入门实战 05：温湿度传感器

入门实战

DHT11 读数

#include <DHT.h>
DHT dht(4, DHT11);

void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  Serial.printf("T=%.1f H=%.1f\n", t, h);
  delay(2000);
}

这就是智能加湿器、农业监测的核心传感器。下一步通过 BLE 发给 iPhone 显示。
