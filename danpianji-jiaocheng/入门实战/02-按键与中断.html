入门实战 02：按键与中断

入门实战

轮询 vs 中断

  • 轮询：while(1) 里不断读按键——费 CPU
  • 中断：按键按下 → 硬件自动跳转到处理函数——像 iOS 的 target-action
void IRAM_ATTR onButton() {
  // 中断服务函数：尽量短！
  flag_pressed = true;
}

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(BUTTON_PIN), onButton, FALLING);
}
