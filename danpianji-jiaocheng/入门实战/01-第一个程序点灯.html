入门实战 01：第一个程序——点灯

入门实战

目标

让 LED 每秒闪一次——嵌入式界的 Hello World。

Arduino 代码（ESP32）

#define LED_PIN 2

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(115200);
  Serial.println("Hello Embedded!");
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);
  digitalWrite(LED_PIN, LOW);
  delay(500);
}

步骤

  1. 板子选 ESP32 Dev Module
  2. 按 GPIO 接线图接 LED
  3. 上传 → 看 LED 闪烁 + 串口输出
