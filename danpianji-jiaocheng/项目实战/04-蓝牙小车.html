项目实战 04：蓝牙小车

项目实战

L298N 电机+BLE 方向控制，JoyStick UI。

要点说明
实验DevKit 验证
调试串口 printf

1. 硬件

ESP32/STM32 + L298N + 2DC电机 + 电池

2. 协议

Char 0x01: [left_pwm, right_pwm] int8 -100~100

3. App

SwiftUI Joystick → BLE write 20Hz；dead zone 防 drift。

4. 安全

超时 500ms 无指令自动停车。

💡 电机干扰大，电源电容+去耦；BLE 天线远离电机。

常见问题

PID?

循迹进阶。

Wi-Fi 版?

MQTT 远控但延迟大。

电池?

2S LiPo+保护。

本章小结

  • BLE 低延迟控车
  • Joystick UI
  • 超时停车
  • 电源去耦
