1. 使用说明

先自答再展开。校招/社招基础岗常从中抽 5-10 题。

2. 题目与答案

1. 什么是 MCU？

参考答案

集成 CPU、存储、外设的单芯片控制器，面向嵌入式控制。

2. Flash 和 RAM 区别？

参考答案

Flash 掉电保持存程序；RAM 掉电丢失存变量。

3. 解释 GPIO 推挽输出。

参考答案

内部 PMOS+NMOS 可主动输出高或低。

4. 什么是中断？

参考答案

硬件事件打断 CPU 执行 ISR，再返回。

5. UART 需要几根线？

参考答案

至少 TX/RX/GND 三根。

6. I2C 总线两根线叫什么？

参考答案

SDA 数据线、SCL 时钟线。

7. SPI 片选 CS 作用？

参考答案

多从设备时选择当前通信对象。

8. 什么是波特率？

参考答案

串口每秒传输的符号数，常用 115200。

9. 指针是什么？

参考答案

存放内存地址的变量。

10. volatile 关键字？

参考答案

告诉编译器不要优化对该变量的访问。

11. 堆和栈区别？

参考答案

栈自动管理局部变量；堆 malloc 手动 free。

12. 什么是 PWM？

参考答案

脉宽调制，用占空比模拟模拟量或控舵机。

13. ADC 作用？

参考答案

模拟电压转数字量。

14. 看门狗 IWDG 作用？

参考答案

超时复位防程序跑飞。

15. CAN 总线特点？

参考答案

差分、多主、抗干扰，汽车常用。

16. Modbus RTU 物理层？

参考答案

通常 RS485。

17. BLE GATT 三层？

参考答案

Service → Characteristic → Descriptor。

18. Notify 和 Read 区别？

参考答案

Notify 设备主动推；Read 主机主动读。

19. FreeRTOS Task 创建函数？

参考答案

xTaskCreate。

20. Mutex 解决什么问题？

参考答案

多任务访问共享资源互斥，防竞态。

21. Queue 用途？

参考答案

任务间安全传递数据。

22. ESP32 Deep Sleep 唤醒方式？

参考答案

定时器、GPIO、RTC 等。

23. NVS 是什么？

参考答案

ESP32 非易失键值存储。

24. OTA 双分区目的？

参考答案

升级失败可回滚旧固件。

25. STM32 HAL 和 LL？

参考答案

HAL 抽象易用；LL 接近寄存器高效。

26. CubeMX 作用？

参考答案

图形化配引脚时钟并生成初始化代码。

27. SWD 几根线？

参考答案

SWDIO/SWCLK/GND/3.3V。

28. Brownout 复位？

参考答案

供电电压过低时 MCU 复位保护。

29. 上拉电阻作用？

参考答案

为开漏/输入提供默认高电平。

30. 逻辑分析仪用途？

参考答案

抓取数字时序，解码 I2C/SPI/UART。

31. MQTT pub/sub？

参考答案

发布订阅模式，解耦设备与 App。

32. QoS 0/1/2 区别？

参考答案

0 最多一次；1 至少一次；2 恰好一次。

33. WiFi STA 模式？

参考答案

Station 连接现有路由器。

34. 3.3V 和 5V GPIO 能混接吗？

参考答案

不能，5V 进 3.3V GPIO 会损坏。

35. struct 和 class？

参考答案

C 的 struct 无方法默认；C++ struct 可含方法。

36. 位操作置位公式？

参考答案

reg |= (1 << n)。

37. Mem_Read I2C？

参考答案

HAL_I2C_Mem_Read 带寄存器地址读。

38. DMA 好处？

参考答案

外设与内存直传，减 CPU 占用。

39. Tickless Idle？

参考答案

空闲时停 SysTick 进低功耗。

40. Bootloader 作用？

参考答案

上电加载/升级 App 固件。

41. MISRA C？

参考答案

汽车等安全关键领域的 C 编码规范子集。

42. CoreBluetooth Central？

参考答案

iPhone 扫描连接外设的角色。

43. NSBluetoothAlwaysUsageDescription？

参考答案

iOS 蓝牙权限说明，必填。

44. SmartConfig 是什么？

参考答案

手机通过 Wi-Fi 编码广播 SSID 给 ESP。

45. CocoaMQTT 用途？

参考答案

iOS MQTT 客户端库。

46. HomeKit 门槛？

参考答案

MFi 认证，门槛高于自建 BLE。

47. Edge AI on MCU？

参考答案

TinyML 在 MCU 跑推理，如唤醒词。

48. Matter 协议？

参考答案

智能家居互操作标准，基于 IP。

49. Resume 嵌入式项目怎么写？

参考答案

量化：独立完成固件+App，写了什么协议，解决什么 bug。

50. 如何排查 HardFault？

参考答案

看 LR/PC，查 CFSR/HFSR，用 GDB 反汇编。
