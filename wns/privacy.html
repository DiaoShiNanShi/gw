Privacy Policy

隐私政策

最后更新：2026 年 9 月 4 日

概述

wifi共享钥匙（以下简称「本 App」）是一款帮助您在本机管理 Wi-Fi 密码、分享访客二维码，并进行可选网络诊断的工具类应用。您保存的 Wi-Fi 密码与备注存储在设备本地，我们不会要求您注册账号，也不会将密码上传至我们的服务器。

广告与第三方 SDK

本 App 免费使用，由第三方广告服务（穿山甲 / Pangle 及其聚合 SDK）支持。从第二次冷启动起可能展示开屏广告，首页底部可能展示 Banner 广告。广告 SDK 可能处理设备标识符、广告展示与点击等数据，用于广告投放、归因与效果衡量。您可在 iOS「设置 → 隐私与安全性 → 跟踪」中管理 App 跟踪授权（ATT）。

我们收集什么

除上述广告相关数据外，本 App 不会将您的 Wi-Fi 密码或个人备注上传到我们的服务器。检测历史保存在设备本地。

广告 SDK 可能收集崩溃与性能相关数据，用于 SDK 稳定性与广告服务优化，不会用于识别您的 Wi-Fi 密码内容。

设备权限用途

  • 定位（使用时）：仅用于读取当前连接的 Wi-Fi 名称（SSID），系 iOS 系统要求。我们不会追踪或上传您的地理位置。
  • 本地网络：用于局域网设备探测与网关连通性诊断。
  • 相机：用于扫描 Wi-Fi 二维码。
  • 面容 ID / Touch ID：可选，用于解锁密码本。
  • 通知：仅在您为临时 Wi-Fi 设置过期提醒时使用。
  • App 跟踪透明度（ATT）：可选，用于向您展示更相关的广告。

网络请求

测速、DNS 测试、门户检测、广告加载等功能会向第三方服务器发起网络请求，仅用于实现对应功能，不包含您的 Wi-Fi 密码。部分广告素材可能通过 HTTP 加载（穿山甲 SDK 集成要求），您的 Wi-Fi 密码不会经此通道传输。

数据共享与删除

我们不会出售您的 Wi-Fi 密码。广告数据由第三方广告服务商按其隐私政策处理。您通过系统分享功能主动分享的二维码或海报由您自行控制接收方与分享范围。删除 App 即可删除所有本地保存的密码与记录。

数据存储与安全

Wi-Fi 密码等敏感信息优先存储在 iOS Keychain 中。其他应用数据保存在 App 沙盒内，受 iOS 系统隔离保护。您可在设置中开启面容 ID 作为额外访问保护。

儿童隐私

本 App 不面向 13 岁以下儿童，也不会故意收集儿童信息。

政策更新

我们可能适时更新本隐私政策。更新后的版本将发布在本页面，并修改文首「最后更新」日期。
